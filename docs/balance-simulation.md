## 一、核心公式汇总

### 1.1 单词得分公式

```
baseChips = letterCount × 1 + skillBaseScore + letterBaseScore + wordBonus
multiplier = 1.0 + combo × 0.1 + skillMultBonus
finalWordScore = floor(baseChips × multiplier × bonusMult)
```

### 1.2 关卡目标公式

```
Stage 1: calibratedTargetBase（校准关，以玩家实际得分为基线）
Stage N (N≥2): calibratedBase × 1.45^(N-2)
Boss 关: target × 1.5
每周目时间衰减: timeLimit × 0.9^(cycleIndex)
```

### 1.3 技能触发产出

```
Phase 1: base = baseValues[level-1]
Phase 2: output = effectiveBase × (1 + bonusPercent)   [加算]
Phase 3: output × critMult × cascadeMult × ...          [乘算]
Phase 4: 路由到对应资源（base→synergy, score→直接, mult→synergy）
```

## 六、关键发现

### 6.1 精英关(S5)是首个压力点 — 设计合理 ✅

精英关的弱化修饰器 + 此时技能尚未成型，构成了第一道真实考验。余量 0.89× 意味着：
- 打得好的玩家勉强通过
- 需要商店决策得当（优先升级而非囤新技能）
- **这个压力点是好的设计**，让玩家感受到修饰器的威胁

### 6.2 S7 之后词缀联动产生跳跃 — 需要关注

Stage 7 的余量突然回升到 1.89×，原因是：
- 覆盖率从 35% → 50% 是质变拐点
- 词缀叠层效果（Pulse/Resonance）开始联动
- **问题：** S5 紧张 → S7 突然宽裕，体验可能不够平滑

### 6.3 ❌ Boss 关(S12)产出严重不足

目标 6380 vs 产出 2595，缺口高达 **2.46倍**。这意味着：

**可能原因分析：**

1. **校准基线过低？** 如果 S1 校准分=150，则 S12 目标 = 150 × 1.45¹⁰ × 1.5 ≈ 6380。1.45 的 10 次方 = 28.4×，加上 Boss 的 1.5× 就是 42.6×。要求玩家在 11 关内将单词产出提升 42 倍。

2. **实际校准值可能更高：** 如果好的玩家 S1 打出 300 分，则 S12 目标 = 12760。缺口更大。但反过来，高分玩家本身每词产出也更高。

3. **模拟低估了后期爆发：** 真实游戏中以下因素可能使产出大幅超出线性预期：
   - Pulse 叠层 20 层后一次释放（×20 单次产出）
   - Recurse 递归触发（一次触发 → 2-3 次额外产出）
   - Splash/Relay 链式传播（一次击键触发 3-4 个技能）
   - 质变任务完成后技能质变（产出翻倍级提升）
   - 学徒附魔的累积成长（+100% 到 +200%）

### 6.4 base vs score 资源的效率对比

```
场景: Lv2 技能, multiplier = 2.5

base 技能 (Lv2=8):
  → 贡献到 baseChips → 8 × 2.5 = 20 等效分

score 技能 (Lv2=24):
  → 直接加分 → 24 等效分

分界点: 当 multiplier = 24/8 = 3.0 时 base 追平 score
  → multiplier > 3.0 后 base 型更优
  → 这通常发生在 Stage 8-10 左右（combo 10+, mult技能累积）
```

**设计意义：** 早期 score 直加更可靠，后期 base+mult 组合更强。这创造了自然的 build 演进路径。

### 6.5 multiplier 资源的投资回报

```
1 个 mult Lv1 技能, 触发率 15%:
  5 字母词期望触发 0.75 次 → 贡献 0.75 × 0.20 = +0.15 mult

对 baseChips=15 的词: +0.15 mult → +2.25 分/词
对 baseChips=30 的词: +0.15 mult → +4.50 分/词

vs 1 个 base Lv1 技能, 触发率 15%:
  期望贡献 0.75 × 5 = +3.75 base → 3.75 × mult 分/词

分界点: mult 技能在 baseChips > 3.75/0.15 = 25 时更优
  → 约 Stage 8+ (5-6 个技能叠加后)
```

## 七、平衡建议

### 7.1 Boss 关难度可能需要校准

当前 `1.45^10 × 1.5 = 42.6×` 的难度膨胀可能过高。建议考虑：

- **方案 A:** 降低 TARGET_GROWTH 从 1.45 → 1.38（S12 目标降至 ~4200，缺口缩小到 1.6×）
- **方案 B:** 降低 BOSS_TARGET_MULT 从 1.5 → 1.3
- **方案 C:** 不改数值，但确认后期爆发机制（Pulse/Recurse/Splash 链）能可靠产出 6000+ 分

### 7.2 S5(Elite) → S7 的体验断层

从 0.89× 余量跳到 1.89× 太突然。建议：
- 让 S6 的附魔选择更有策略性（而非纯加强）
- 或在 S7 目标上加一个小系数补偿

### 7.3 模拟的局限性

本推演 **没有** 充分建模以下后期核心机制：
- Pulse/Resonance 叠层爆发（可能是 10-50× 单次产出）
- Recurse 递归（1 → 3 次触发）
- Splash/Conduit/Relay 链式传播
- 质变任务的质变加成
- 学徒附魔的永久成长
- 遗物系统的整体增幅

**建议下一步：** 建模一个后期 "成型 build" 的单词期望产出，包含完整词缀联动，验证 Boss 关是否真的不可达还是模拟低估。

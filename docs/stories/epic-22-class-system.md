# Epic 32: 职业系统 + 造词师 + 蜕变师

## 概述

引入职业系统，为游戏的核心循环增加 Replayability。每个职业控制不同的游戏维度（输入/处理/规则），通过独有机制、独有资源和「失去」某项通用能力来实现机制差异化（而非数值差异化）。

首批实现两个设计完成的职业：
- **造词师（Word Architect）**：操控输入层，通过字母碎片 + 采集队列 + 造词台手动构建词库
- **蜕变师（Metamorph）**：操控处理层，通过变异素 + 隐藏池 + 蜕变盲盒改造技能组合

设计文档：`docs/class-design-wordsmith.md`、`docs/class-design-metamorph.md`

## 设计目标

- **机制差异化：** 每个职业有独有的核心机制和资源类型，而非数值加成
- **「失去」机制：** 每个职业失去一项通用能力，避免纯加法式强化
- **框架可扩展：** 第三个职业（寄生者）及未来职业可在同一框架下接入
- **零侵入：** 无职业（默认模式）的体验完全不受影响
- **渐进式实现：** 框架先行，两个职业分别独立实现

## 职业总览

| | 造词师 | 蜕变师 |
|---|---|---|
| 操控层 | 输入层（词语） | 处理层（技能） |
| 独有资源 | 字母碎片（26 种，第 7 种资源） | 变异素（1 种，第 8 种资源） |
| 核心操作 | 造词台拼词 → 进词库 | 蜕变盲盒 → 技能变形 |
| 操作时机 | 商店·造词台 tab | 关卡结算·蜕变阶段 |
| 失去 | 牌包系统（商店无牌包 tab） | 附魔选择权（Lv3 随机附魔） |
| 确定性 | 高（自选字母拼词） | 低（纯盲盒） |
| 构筑风格 | 精密工程师 | 进化赌徒 |

## Story 拆分

### Phase A：职业系统框架

---

### Story 32.1: 职业定义框架 + 选择界面
**复杂度：中**

定义职业系统核心数据结构，实现 Run 开始时的职业选择界面。

验收标准：
- ClassDefinition 接口定义完成：
  ```typescript
  interface ClassDefinition {
    id: ClassId                    // 'wordsmith' | 'metamorph' | 'none'
    name: string                   // 显示名
    description: string            // 职业描述
    uniqueResource: ResourceType   // 独有资源类型
    loseFeature: FeatureId         // 失去的能力
    starterRelic: RelicId          // 初始遗物
  }
  ```
- ClassManager 管理职业注册和当前选中职业
- RunState 新增 `classId: ClassId` 字段
- 职业选择界面（RunStart 场景中）：展示可选职业 + 说明 + 确认
- 选择「无职业」可跳过（默认模式）
- 选中职业后 starterRelic 自动加入背包
- MetaState 追踪已解锁职业

### Story 32.2: 职业专属资源管道
**复杂度：高**

扩展 ResourceType 枚举支持职业专属资源，实现资源产出/转化的职业条件过滤。

验收标准：
- ResourceType 新增 `fragment`（第 7 种）和 `mutagen`（第 8 种）
- 职业专属资源仅在对应职业激活时启用
- BattleState 新增职业资源累计产出计数器（每关归零）
- 转化者读取职业资源时使用**本关累计产出量**（非库存）
- 职业资源的产出者/转化者使用现有技能框架，无特殊路径
- RunState 管理跨关持久化的职业资源库存（碎片 26 池 / 变异素 1 池）
- 非激活职业的资源类型完全隐藏（UI + 逻辑）

### Story 32.3: 职业「失去」机制框架
**复杂度：低**

实现职业「失去」机制的条件检查框架。

验收标准：
- FeatureGate 系统：根据当前职业决定功能是否可用
  ```typescript
  featureGate.isEnabled('pack-system')    // 造词师 → false
  featureGate.isEnabled('enchant-choice') // 蜕变师 → false
  ```
- 商店系统读取 FeatureGate 决定是否显示牌包 tab
- 附魔系统读取 FeatureGate 决定 Lv3 是二选一还是随机
- 无职业时所有 feature 默认 enabled
- 失去的能力有 UI 提示（灰色 + tooltip 说明原因）

### Phase B：造词师

---

### Story 32.4: 造词师 — 字母碎片资源 + 采集队列
**复杂度：高**
**依赖：32.2**

实现造词师核心机制：26 种字母碎片资源和循环采集队列。

验收标准：
- 字母碎片库存：26 个独立计数器（A-Z），跨关保留，Run 结束清零
- 采集队列（Collection Queue）：
  - 长度 6-8 格（基础 6，遗物可扩展）
  - 玩家设定队列字母序列，如 `[E, E, A, T, S, _]`
  - 空格 `_` 不产碎片（跳过）
  - 碎片产出时按队列顺序循环推进
  - 设一次 → 整个 Run 内有效，直到玩家修改
- 概率溢出机制：
  - `floor(base × multiplier)` = 保底碎片数
  - `frac(base × multiplier)` = 额外碎片概率
  - 产多碎片时队列前进对应格数
- 采集队列同时服务产出者和转化者的碎片输出端
- 单元测试覆盖概率溢出边界情况

### Story 32.5: 造词师 — 碎片产出者 + 碎片转化者
**复杂度：中**
**依赖：32.2, 32.4**

实现碎片产出者（技能子类型）和碎片与其他资源间的转化者。

验收标准：
- 碎片产出者：`resource=fragment` 的产出者，套现有产出者公式
- 碎片产出者同时有微量 `base_score`（不是纯死权重）
- 碎片→其他资源转化者：输入读 BattleState 累计碎片产出量（非库存）
- 其他资源→碎片转化者：输出走采集队列
- 碎片产出者全类型附魔兼容（成长/共鸣/溅射/排斥/变性/精通/吞噬）
- 花碎片造词不影响转化者读数
- 转化者计数器每关归零

### Story 32.6: 造词师 — 造词台 UI + 造词逻辑
**复杂度：高**
**依赖：32.4, 32.5**

实现商店内的造词台标签页，包含队列编辑和造词交互。

验收标准：
- 商店新增「造词台」tab（替换牌包 tab，依赖 32.3 FeatureGate）
- 造词台界面包含：
  - 采集队列编辑区（点击格子 → 字母选择器）
  - 当前碎片库存展示（26 字母 + 数量）
  - 造词输入区（逐字母选择）
  - 消耗预览（碎片 + 金币）
  - 已造词列表
- 造词消耗规则：
  - 碎片：1:1 线性消耗
  - 金币：重复字母递增（0g / 5g / 15g / 30g）
- 造出的词进入当前 Run 词库
- 造词操作不可撤销（除非有拆词剪刀遗物）
- 碎片不足 / 金币不足时按钮灰色 + 提示

### Story 32.7: 造词师 — 专属附魔 + 专属遗物
**复杂度：中**
**依赖：32.4, 32.5, 32.6**

实现造词师 3 个专属附魔和 7 个专属遗物。

验收标准：
- **专属附魔**（不进入通用附魔池）：
  - 丰收：每造一个词，本技能永久 +8%（RunState 跨关保留）
  - 字母亲和：绑定键位字母出现在采集队列中时 +25%
  - 满溢：任一字母碎片 ≥15 时 +20%，每多一种 ≥15 额外 +5%
- **专属遗物**：
  - 学徒笔记（common/初始）：开局元音碎片各 ×3
  - 大师词典（legendary/Boss 池）：全 26 字母 ×2 + 队列 +2
  - 永动队列（rare）：每关开始自动触发队列一轮
  - 精炼透镜（rare）：碎片→其他转化读数 +30%
  - 拆词剪刀（rare）：可拆解已造词，返还 50% 碎片
  - 共鸣字模（legendary）：重复字母不收金币
  - 碎片棱镜（legendary）：队列每格同时产相邻字母碎片
- 专属附魔/遗物仅在造词师激活时进入候选池

### Phase C：蜕变师

---

### Story 32.8: 蜕变师 — 隐藏池系统 + 变异素资源
**复杂度：高**
**依赖：32.2**

实现隐藏池分配机制和变异素资源。

验收标准：
- Run 开始时（蜕变师激活），转化者/连接者/增幅者总池各随机 50/50 分为可见池和隐藏池
- 产出者不分池（全部可见）
- 分池受 Run 种子影响，整个 Run 内不变
- 商店仅刷可见池技能
- 非蜕变师时无分池，全部技能可见
- 变异素资源：单一类型，跨关保留，Run 结束清零
- 变异素产出者：套现有产出者公式
- 变异素转化者交互：读本关累计产出量，非库存
- HUD 显示变异素数量（战斗中）

### Story 32.9: 蜕变师 — 蜕变核心机制 + 结算阶段 UI
**复杂度：高**
**依赖：32.8**

实现关卡结算时的蜕变阶段和蜕变核心逻辑。

验收标准：
- 关卡结算流程新增蜕变阶段（在商店之前）
- 蜕变阶段 UI：
  - 展示所有当前技能（可点击）
  - 显示持有变异素数量
  - 点击技能 → 消耗 1 变异素 → 蜕变动画 → 揭示新技能
- 蜕变规则：
  - 技能类型不变（产出→产出，转化→转化...）
  - 从隐藏池同类型中随机抽取
  - 全继承：等级 / 附魔 / 成长值保留
  - 不可反悔
  - 纯盲盒：不可预览不可选择
- 可连续蜕变多个技能（变异素充足时）
- 可跳过蜕变阶段
- 剩余变异素保留到下一关
- 蜕变动画：旧技能碎裂 → 新技能从碎片中凝聚

### Story 32.10: 蜕变师 — 附魔随机化 + 专属附魔 + 专属遗物
**复杂度：中**
**依赖：32.3, 32.9**

实现蜕变师的附魔选择权剥夺、3 个专属附魔和 7 个专属遗物。

验收标准：
- **附魔随机化**（依赖 FeatureGate）：
  - 蜕变师技能 Lv3 时直接随机赋予 1 个附魔（不给二选一）
  - UI 显示「随机附魔」动画而非选择界面
- **专属附魔**（不进入通用附魔池）：
  - 适应：每被蜕变一次 +15%（RunState 跨关保留，无论变成什么都保留）
  - 不稳定：每关开始随机一种资源 +30%，关末消失
  - 嗜变：触发时 5% 概率产 1 变异素（不占产出者槽位）
- **专属遗物**：
  - 原初变异体（common/初始）：每关第一次蜕变免费
  - 终极突变株（legendary/Boss 池）：每关前两次蜕变免费 + 高稀有度结果返 1 变异素
  - 基因稳定器（rare）：本关再次蜕变同一技能消耗减半
  - 催化注射器（rare）：变异素→其他转化读数 +30%
  - 混沌种子（rare）：每关结束随机一个未附魔技能获随机附魔
  - 深渊之眼（legendary）：商店预览 2 个隐藏池技能（仅展示）
  - 适者生存（legendary）：蜕变后技能本关 +20%
- 专属附魔/遗物仅在蜕变师激活时进入候选池

### Phase D：集成

---

### Story 32.11: 职业系统集成测试 + 平衡
**复杂度：中**
**依赖：32.7, 32.10**

端到端集成测试，验证两个职业的完整 Run 流程和平衡性。

验收标准：
- 无职业模式完全不受职业系统影响（回归测试）
- 造词师完整 Run：选职业 → 碎片产出 → 造词 → 使用造词 → 通关
- 蜕变师完整 Run：选职业 → 变异素产出 → 蜕变 → 使用变形技能 → 通关
- 职业切换无残留状态（Run A 选造词师 → Run B 选蜕变师）
- 职业专属资源不出现在非对应职业的任何 UI 中
- FeatureGate 正确控制牌包/附魔选择
- 两个职业的存档/读档正确（RunState 序列化含职业数据）
- 性能：职业系统不引入额外帧延迟

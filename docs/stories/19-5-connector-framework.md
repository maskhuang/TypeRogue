# Story 19.5: 连接者框架与连锁规则（36 个）

## Story

作为一个 **玩家**，
我想要 **连接者技能自动触发位置关系内的其他技能，形成连锁反应**，
以便 **通过键盘布局构建复杂的触发链，实现"键盘即棋盘"的核心 build 体验**。

## Acceptance Criteria

- [ ] AC1: `ConnectorSkill` 接口定义完成：triggerType(复制/资源触发), positionRelation, 触发条件
- [ ] AC2: 6 个复制型连接者实现（每种位置关系 1 个）：当自身触发时，自动触发关系内的一个随机技能
- [ ] AC3: 30 个资源触发型连接者实现（5 资源 × 6 位置关系）：当关系内技能产出特定资源时，自身触发一次
- [ ] AC4: 连接者固定 Lv1，不可升级，不可进化
- [ ] AC5: 每局 run 从 36 个连接者中随机抽 18 个进入技能池
- [ ] AC6: **三层连锁保护规则**实现：
  - Layer 1：2 卡直接循环禁止（A触发B且B触发A → 阻断）
  - Layer 2：3+ 卡跨资源循环允许（奖励复杂 build）
  - Layer 3：伪无限安全阀（检测到循环时，所有循环技能以 4 次/秒速率持续整关，玩家可同时打字）
- [ ] AC7: 连接者被触发时有视觉反馈（连续弹出浮字形成节奏感）
- [ ] AC8: 单元测试覆盖所有连锁场景（单链、分叉、循环、伪无限）

## Dev Notes

### 连接者分类

**复制型（6 个）:**

| 位置关系 | emoji | 名字 | 效果 |
|---|---|---|---|
| 相邻 | 🔗 | 链接 | 触发时复制到相邻键一个随机技能 |
| 同行 | 📡 | 广播 | 触发时复制到同行一个随机技能 |
| 同列 | 📌 | 穿刺 | 触发时复制到同列一个随机技能 |
| 同手 | 🤝 | 握手 | 触发时复制到同手一个随机技能 |
| 同指 | 👆 | 指尖 | 触发时复制到同指一个随机技能 |
| 对称位 | 🪞 | 镜像 | 触发时复制到对称位技能 |

**资源触发型（30 个）:** 5 资源 × 6 位置关系

### 三层连锁规则详解

- **Layer 1**：任何单步触发检查 chainHistory，若目标已在栈中且链长=2，阻断
- **Layer 2**：链长≥3 的循环检测到后放行到 Layer 3
- **Layer 3**：退出正常链式执行，进入定速自动模式（4/sec × 循环技能数）

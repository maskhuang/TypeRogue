# Epic 31: 数字 Juice 体系

## 概述

让玩家**感受到数字的重量**。通过视觉（颜色/大小/动画）、听觉（音效）、触觉（震动）三个通道，把 build 的威力从抽象数字变成感官冲击。越强的 build 产出越大的数字，越大的数字带来越猛的反馈，形成正向心流循环。

本 Epic 源自头脑风暴 P1 优先级方向（`docs/brainstorming-session-2026-03-04.md`，Epic 候选 B）。

## 设计目标

- **信息丰富的 Juice：** 每一层视觉/音效反馈都承载信息（量级、冲击力、频率），而非纯装饰
- **渐进式感知：** 玩家随 build 变强逐步解锁更高量级的视听反馈，形成成长曲线
- **零认知负荷：** 所有反馈都是被动感知的，不增加战斗决策压力
- **60fps 硬约束：** 所有动画/粒子效果必须在渲染预算内运行

## 数字颜色分级

| 分数区间 | 颜色 | 视觉效果 |
|----------|------|----------|
| 0-99 | 白色 | 普通文字 |
| 100-999 | 金色 | 金色文字 + 微光 |
| 1000-4999 | 彩虹 | 彩虹渐变 + 流动效果 |
| 5000-9999 | 发光 | 发光文字 + 光晕 |
| 10000+ | 粒子爆发 | 发光 + 粒子喷射 |

## 屏幕震动分级

| 分数区间 | 震动强度 | 持续时间 |
|----------|----------|----------|
| 100-499 | 微震（2px） | 0.1s |
| 500-999 | 轻震（4px） | 0.15s |
| 1000-4999 | 中震（6px） | 0.2s |
| 5000-9999 | 强震（10px） | 0.3s |
| 10000+ | 猛震（16px） | 0.4s |

- 震动方向随机
- 支持禁用/强度调节（无障碍设置）

## 数字音效分级

| 分数区间 | 音效特征 |
|----------|----------|
| 小数字 (0-99) | 清脆短促高频 |
| 中数字 (100-999) | 中频明亮 |
| 大数字 (1000-4999) | 低频厚重 |
| 巨数字 (5000+) | 低频轰鸣 + 混响尾巴 |

- 使用 Howler.js 声音池，预加载所有档位音效
- 池大小 ≥ 10（支持快速连续触发）

## 数字动画

- **滚轮效果：** 分数像老虎机逐位翻滚到目标值
- **弹性弹出：** 大数字从小到大弹性动画（overshoot + settle）
- **慢动作结算：** 高分词（≥1000）结算时自动 0.3s 微慢放

## 分数里程碑

| 里程碑 | 庆祝效果 |
|--------|----------|
| 100 | 文字闪光 |
| 500 | 小型粒子爆发 |
| 1000 | 中型粒子 + 音效 |
| 5000 | 大型粒子 + 屏震 + 音效 |
| 10000 | 全屏庆祝 + 特殊音效 + 长余韵 |

- 首次到达每个里程碑有额外一次性庆祝
- 之后每次到达该量级播放标准版

## 关卡评级

| 评级 | 条件 | 视觉 |
|------|------|------|
| C | 刚好达标（100-110%） | 灰色 |
| B | 110-130% | 蓝色 |
| A | 130-160% | 金色 |
| S | 160-200% | 紫色 + 光效 |
| SS | 200-300% | 彩虹 + 粒子 |
| SSS | 300%+ | 全特效 + 独特音效 |

- 百分比 = 实际分数 / 目标分数
- 关卡结束时评级从 C 逐级滚动到最终等级（每级停顿 0.3s）
- 评级动画配合对应量级的屏震和音效

## Story 拆分

### Story 31.1: 数字颜色分级系统
**复杂度：中**

实现分数数字的颜色分级渲染，包含 5 个档位的视觉效果。

验收标准：
- NumberRenderer 组件支持根据分数值自动选择颜色档位
- 白色/金色/彩虹/发光/粒子 5 档视觉效果正确渲染
- 彩虹渐变流动效果平滑（shader 或 PixiJS filter）
- 粒子喷射效果使用对象池，无 GC 压力
- 所有效果 60fps 无卡顿
- 分数变化时颜色档位平滑过渡（非跳变）

### Story 31.2: 屏幕震动分级系统
**复杂度：低**

实现分数触发的屏幕震动反馈，5 个强度档位。

验收标准：
- ScreenShake 系统支持 5 档震动（强度 + 持续时间）
- 震动方向随机，衰减自然
- 多次震动可叠加（取最大强度，不累加）
- 设置菜单中可禁用震动或调节强度（无障碍）
- 震动不影响 UI 元素的点击判定

### Story 31.3: 数字音效系统
**复杂度：中**

实现分数量级对应的差异化音效反馈。

验收标准：
- 4 档分数音效（清脆/明亮/厚重/轰鸣）
- 使用 Howler.js 声音池，每档池大小 ≥ 10
- 音效延迟 < 50ms
- 快速连续触发不卡顿不爆音
- 音量随分数量级适度增大（不刺耳）
- 音效与视觉效果同步触发

### Story 31.4: 数字动画系统
**复杂度：中**

实现数字滚轮、弹性弹出、慢动作结算三种动画效果。

验收标准：
- 滚轮效果：分数逐位从旧值翻滚到新值，持续 0.3-0.8s（视差值大小）
- 弹性弹出：大数字 overshoot 120% → settle 到 100%，弹性曲线自然
- 慢动作结算：分数 ≥ 1000 的词结算时全局 0.7x 速度持续 0.3s
- 动画使用缓动函数，不依赖 setTimeout
- 多词快速连续结算时动画正确排队/覆盖

### Story 31.5: 分数里程碑庆祝
**复杂度：低-中**

实现分数里程碑（100/500/1000/5000/10000）的庆祝效果。

验收标准：
- 5 个里程碑等级各有独特庆祝效果
- 首次到达里程碑有强化版一次性庆祝
- 粒子效果使用对象池
- 庆祝效果不遮挡关键 UI（词语区、计时器）
- 与颜色分级和屏震系统联动

### Story 31.6: 关卡评级系统
**复杂度：中**

实现关卡结束时的 C-SSS 评级系统及评级揭示动画。

验收标准：
- 6 级评级（C/B/A/S/SS/SSS）根据得分比计算
- 评级揭示动画：从 C 逐级滚动到最终评级，每级 0.3s
- 每级有对应颜色和视觉效果
- SS/SSS 评级有粒子和特殊音效
- 评级结果存入 BattleResult，可在战后统计中查看
- 评级渲染组件可复用（结算画面 + 统计面板）

```
31.6 (关卡评级) ← 依赖 31.1 + 31.2 + 31.3
```

# Epic 20: 词库管理 + 字频锁定

## 概述

玩家无法查看自己拥有的全部词语，也无法方便地删词。字频为 0 的字母键绑定技能无意义（战斗中不会出现），需要锁定。本 Epic 新增词库查看/删词面板，并实现零频键位自动锁定。

## 设计目标

- **信息透明：** 玩家可随时查看完整词库，高亮已绑定字母
- **策略调整：** 支持付费删词（3 金币），主动调整字频分布
- **防呆设计：** 零频键位灰显、禁拖拽、自动解绑，避免无效 build

## Story 拆分

### Story 20.1: 词库查看与删词
**复杂度：低**

商店右侧面板新增词库列表，显示所有已拥有词语，支持花费 3 金币删除。

### Story 20.2: 零频键位锁定
**复杂度：低**
**依赖：20.1（共享字频计算）**

字频为 0 的键位灰显、禁止绑技能、自动解绑已有技能、购买自动绑定跳过。

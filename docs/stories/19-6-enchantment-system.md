# Story 19.6: 附魔系统（33 个）

## Story

作为一个 **玩家**，
我想要 **技能升到 Lv3 时进化获得附魔，根据键盘位置关系产生额外效果**，
以便 **通过附魔选择进一步深化键盘布局策略，创造独特的邻居效应 build**。

## Acceptance Criteria

- [ ] AC1: 技能达到 Lv3 时触发进化 UI：从 33 个附魔池中随机抽 2 个，选 1 个附上
- [ ] AC2: 24 个空间型附魔实现（4 效果类型 × 6 位置关系）：增幅/溅射/共鸣/排斥
- [ ] AC3: 5 个变性型附魔实现：触发时额外产出另一种资源（目标资源增量 × 系数）
- [ ] AC4: 4 个独立型附魔实现：先手/终幕/一刀/渴血
- [ ] AC5: 空间型附魔正确使用 KeyboardTopology 查询位置关系
- [ ] AC6: 变性型附魔产出**可以**触发连接者（设计决策：有达成难度的无限是奖励）
- [ ] AC7: 附魔效果在战斗中正确触发并有视觉反馈（浮字标注来源）
- [ ] AC8: 进化选择 UI：显示 2 个附魔的名字、效果说明，点击选择
- [ ] AC9: 连接者不可进化（maxLevel=1，无附魔）
- [ ] AC10: 单元测试覆盖每种附魔类型的效果计算

## Tasks / Subtasks

- [ ] Task 1: 附魔数据定义 (AC: 2, 3, 4)

  - [ ] 1.2 定义 24 个空间型附魔数据
  - [ ] 1.3 定义 5 个变性型附魔数据
  - [ ] 1.4 定义 4 个独立型附魔数据

- [ ] Task 2: 进化流程 (AC: 1, 8, 9)
  - [ ] 2.1 检测 Lv3 触发：技能升级时检查是否达到 Lv3 + 非连接者
  - [ ] 2.2 从附魔池随机抽 2 个（排除已附魔的重复类型）
  - [ ] 2.3 弹出进化选择 UI（卡牌式，显示效果预览）
  - [ ] 2.4 选择后将附魔绑定到技能

- [ ] Task 3: 空间型附魔效果引擎 (AC: 2, 5)
  - [ ] 3.1 增幅型：检查位置关系内有同资源技能时效果 ×1.5
  - [ ] 3.2 溅射型：触发时额外触发位置关系内一个技能（效果 50%）
  - [ ] 3.3 共鸣型：位置关系内每有一个技能，效果 +20%
  - [ ] 3.4 排斥型：位置关系内无同类型技能时效果 ×2

- [ ] Task 4: 变性型附魔效果 (AC: 3, 6)
  - [ ] 4.1 读取目标资源增量 × 系数（基数 0.3 / 分数 0.3 / 倍率 0.1 / 时间 0.2 / 护盾 0.15）

- [ ] Task 5: 独立型附魔效果 (AC: 4)

- [ ] Task 6: 视觉反馈 (AC: 7)

## Dev Notes

### 33 个附魔分类

**空间型（24 个）= 4 效果 × 6 位置:**
- 增幅型（🔗⬆️等）：有同资源邻居 → 自身 ×1.5
- 溅射型（🔗💫等）：触发时 50% 效果溅射给邻居
- 共鸣型（🔗🔔等）：每有一个邻居 +20%
- 排斥型（🔗🕳️等）：无同类邻居 → ×2

**变性型（5 个）:** 额外产出另一种资源
**独立型（4 个）:** 不依赖位置关系

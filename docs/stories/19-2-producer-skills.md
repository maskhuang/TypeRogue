# Story 19.2: 产出者技能（10 个）

## Story

作为一个 **玩家**，
我想要 **按键触发绑定的产出者技能直接获得对应资源**，
以便 **通过技能选择和键位布局，在每关建立基础资源产出**。

## Acceptance Criteria

- [ ] AC1: 10 个产出者技能数据定义完成，每个指定产出资源类型和 Lv1/2/3 产出值
- [ ] AC2: 按键触发时，绑定的产出者技能将对应资源值加到 `state.resources`
- [ ] AC3: 技能升级系统：Lv1 基础值、Lv2 ×1.6、Lv3 ×2.4
- [ ] AC4: 每局 run 开始时 10 个产出者全部进入技能池（不随机筛选）
- [ ] AC5: 产出者触发时有视觉反馈（对应资源颜色浮字）
- [ ] AC6: 替代现有技能系统的 active 技能触发逻辑
- [ ] AC7: 所有现有测试通过或适配更新

## Tasks / Subtasks

- [ ] Task 1: 产出者数据定义 (AC: 1)
  - [ ] 1.1 在 `data/skills.ts`（或新建 `data/producers.ts`）定义 `ProducerSkill` 接口
  - [ ] 1.2 定义 10 个产出者数据（id, name, emoji, resourceType, baseLv1, baseLv2, baseLv3）

- [ ] Task 2: 产出者触发逻辑 (AC: 2, 3, 6)
  - [ ] 2.1 重构按键处理：字母匹配后检查绑定的技能，触发产出
  - [ ] 2.2 根据技能等级读取对应产出值
  - [ ] 2.3 将产出值加到 `state.resources[skill.resourceType]`

- [ ] Task 3: 技能池管理 (AC: 4)
  - [ ] 3.1 Run 开始时 10 个产出者全部加入可用池
  - [ ] 3.2 商店刷新时产出者按 Act 权重出现（Act1: 80%）

- [ ] Task 4: 触发反馈 (AC: 5)
  - [ ] 4.1 触发时显示资源颜色浮字（⚔️红, 🪙金, 🔥橙, ⏳蓝, 🛡️银）
  - [ ] 4.2 复用现有粒子爆发效果

- [ ] Task 5: 测试 (AC: 7)
  - [ ] 5.1 每个产出者的资源产出正确性
  - [ ] 5.2 等级升级数值正确（×1.6, ×2.4）
  - [ ] 5.3 触发后 state.resources 正确更新

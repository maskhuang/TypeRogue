# Story 19.8: 商店重设计与新手引导

## Story

作为一个 **玩家**，
我想要 **商店按 Act 进度逐步引入产出者→转化者→连接者，首次获得新类型时有简短提示**，
以便 **自然地学习 build 构建的三个阶段，无需阅读教程**。

## Acceptance Criteria

- [ ] AC1: 商店刷新 3 个技能选项，类型按 Act 权重分配：
  - Act1: 产出者 80% / 转化者 20% / 连接者 0%
  - Act2: 产出者 30% / 转化者 50% / 连接者 20%
  - Act3: 产出者 10% / 转化者 40% / 连接者 50%
- [ ] AC2: 商店支持技能升级购买（已拥有技能再次出现时为升级选项，价格递增）
- [ ] AC3: 商店支持键位重绑定功能
- [ ] AC4: 首次获得产出者时显示 tooltip："产出者：按键直接产出资源"
- [ ] AC5: 首次获得转化者时显示 tooltip："转化者：读取一种资源，转化为另一种"
- [ ] AC6: 首次获得连接者时显示 tooltip："连接者：自动触发位置关系内的技能"
- [ ] AC7: tooltip 为一次性显示，不阻断游戏流程（底部渐隐提示条）
- [ ] AC8: 技能卡片显示新三类型标识（产出者/转化者/连接者 + 对应 emoji）

## Tasks / Subtasks

- [ ] Task 1: Act 权重系统 (AC: 1)
  - [ ] 1.1 定义 `SHOP_WEIGHTS` 按 Act 的权重表
  - [ ] 1.2 重构商店刷新逻辑：按权重抽取技能类型，再从对应池中随机选
  - [ ] 1.3 确保不会刷出已满级（Lv3）的重复技能

- [ ] Task 2: 技能升级购买 (AC: 2)
  - [ ] 2.1 商店中已拥有技能显示为"升级"选项（Lv1→2 或 Lv2→3）
  - [ ] 2.2 升级价格递增（Lv2: 1.5× 基础价, Lv3: 2× 基础价）
  - [ ] 2.3 Lv3 升级时触发附魔进化流程（链接 Story 19.6）

- [ ] Task 3: 键位重绑定 (AC: 3)
  - [ ] 3.1 商店提供"重绑定"选项（固定价格）
  - [ ] 3.2 选择技能 → 选择新键位 → 确认

- [ ] Task 4: 新手 tooltip (AC: 4, 5, 6, 7)
  - [ ] 4.1 在 state 中记录 `tooltipShown: Record<SkillType, boolean>`
  - [ ] 4.2 首次获得时检查并显示对应 tooltip
  - [ ] 4.3 tooltip UI：底部渐隐提示条，3 秒自动消失

- [ ] Task 5: 技能卡片 UI (AC: 8)
  - [ ] 5.1 卡片显示技能类型标签（产出者🟢/转化者🔵/连接者🟡）
  - [ ] 5.2 显示当前等级和升级效果预览

- [ ] Task 6: 测试
  - [ ] 6.1 Act 权重分配正确性（统计分布测试）
  - [ ] 6.2 升级价格和等级递增
  - [ ] 6.3 tooltip 只显示一次

## Dev Notes

### 商店权重表

| Act | 产出者 | 转化者 | 连接者 |
|---|---|---|---|
| Act 1 (Stage 1-3) | 80% | 20% | 0% |
| Act 2 (Stage 4-6) | 30% | 50% | 20% |
| Act 3 (Stage 7-8) | 10% | 40% | 50% |

### 引导节奏

- Act 1：只出产出者 → 学会"按键 → 得资源"
- Act 1 商店：首次出现转化者 → 学会"读资源 → 产另一种"
- Act 2 商店：首次出现连接者 → 学会"自动触发别的技能"
- Act 2 Lv3：首次进化（附魔）→ 学会"位置关系影响效果"
- Act 3：全类型 → 自由构建 build

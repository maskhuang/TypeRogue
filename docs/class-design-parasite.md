# 寄生者 (Parasite)

## 职业概览

| 项目 | 设计 |
|------|------|
| 操控维度 | 规则层（修饰器 / debuff） |
| 核心幻想 | 「别人被迫适应规则，我改写规则。修饰器越多，我越强。」 |
| 独有机制 | 嫁接 + 进化 |
| 独有资源 | 共生值（第 9 种资源） |
| 失去 | 待定（候选：商店刷新 / 技能升级选择） |
| 构筑风格 | 规则操纵者 |

## 前置：Boss 修饰器系统重构

寄生者依赖重构后的修饰器系统。修饰器重构方向已确认：**双面牌**。

### 重构原则

1. 每个修饰器 = **规则改变**，不是单纯数值增减
2. 每个修饰器改变「什么行为被奖励」
3. 每个修饰器自然地测试特定 build 维度
4. 修饰器分层（Lv1 → Lv2 → Lv3），同一修饰器可多次选择升级

### 修饰器分类（按测试维度）

| 类别 | 测试什么 |
|------|---------|
| 触发规则类 | 技能触发时机/顺序 |
| 词汇规则类 | 词库覆盖度/词的使用方式 |
| 资源规则类 | 资源链条鲁棒性 |
| 空间规则类 | 键位布局多样性 |
| 构筑规则类 | 技能搭配/附魔的依赖度 |

### 双面修饰器示例（方向参考，具体设计待细化）

```
🔄 回声词 (Echo)
  规则: 每个词完成后立刻重复出现一次
  正面: 增幅者叠层翻倍、成长附魔触发加速
  反面: 实际打字量翻倍，时间压力剧增
  行为改变: 重复词从负担变成资源

🧊 冻结触发 (Frozen Trigger)
  规则: 每个词前 2 个字母不触发技能，第 3 个起产出 +40%
  正面: 长词后段爆发力极强
  反面: 短词几乎无产出
  行为改变: 技能布局偏向词尾常见字母

⚡ 过载链 (Overload Chain)
  规则: 连接者触发链无上限，但每次链式触发消耗 1 护盾
  正面: 循环 build 理论产出无上限
  反面: 护盾耗尽后链式触发直接扣分
  行为改变: 护盾从「防御」变成「循环燃料」

🎭 身份错乱 (Identity Crisis)
  规则: 每 5 词所有技能随机交换键位
  正面: 可能出现超强空间附魔组合
  反面: 精心布局被打乱
  行为改变: 追求鲁棒 build 而非精密布局

💀 亡语词 (Death Words)
  规则: 每关随机 3 个词标记为死亡词，打完扣 20% 分数，可 Tab 跳过
  正面: 跳过不扣时间，等于免费换词
  反面: 不小心打了则巨额扣分
  行为改变: 新增「读词判断」决策层

🌀 资源漩涡 (Resource Vortex)
  规则: 每 10 秒两种资源交换产出通道
  正面: 某些时段资源通道更直接
  反面: 资源链条周期性打乱
  行为改变: 抓节奏窗口爆发
```

### 调研依据

- **Curse of the Dead Gods**: 每个诅咒改变什么行为被奖励（嗜血=必须击杀回血→鼓励激进）
- **Balatro Boss Blinds**: 28 种规则改变测试不同 build 弱点
- **Hades Pact of Punishment**: 玩家自选苦难组合，选择权 = 策略感
- **Monster Train**: 提前预览 Boss 修饰器，从「不公平惊喜」变成「战略约束」
- **Vampire Survivors Curse**: 风险和回报走同一通道，玩家主动追求更高诅咒

详细调研记录见本次会话。

## 核心机制：嫁接 + 进化

### 嫁接 (Graft) — 从修饰器汲取力量

将修饰器的规则效应转化为特定技能的增益。

**规则**:
- 每个修饰器只能嫁接到 1 个技能
- 每个技能只能承载 1 个嫁接
- 嫁接免费，在修饰器选择后立刻操作
- 可以在商店重新分配嫁接

**效果方向**: 被嫁接的技能免疫该修饰器的 debuff，并从规则改变中获得额外增益。

**示例（方向参考，具体待细化）**:
```
「回声词」嫁接到增幅者 → 回声词期间叠层速度 ×3
「冻结触发」嫁接到产出者 → 免疫冻结 + 被冻结字母充能该产出者
「亡语词」嫁接到连接者 → 跳过死亡词时触发完整触发链
```

### 进化 (Evolve) — 改写修饰器规则

消耗共生值，将修饰器的规则变异为新版本。

**规则**:
- 消耗共生值（独有资源）
- 每个修饰器只能进化一次，不可逆
- 在关卡结算时操作
- 进化改变全局规则

**效果方向**: 修饰器的规则变异为不同形式，保留挑战性但改变哪些行为被奖励。

**示例（方向参考，具体待细化）**:
```
「回声词」→「共鸣词」: 不再重复打，改为自动回放上一词的触发序列
「冻结触发」→「蓄力触发」: 被冻结的触发存储，词完成时一次性释放
「身份错乱」→「共生错位」: 从随机交换变为玩家主动选择交换哪两个技能
「亡语词」→「献祭词」: 打死亡词变为 +30% 分数但消耗护盾
```

### 双操作决策张力

```
共生值有限 →

策略 A「少进化多嫁接」: 保持原版规则，嫁接把 debuff 转化为个别技能 buff
策略 B「多进化少嫁接」: 改写规则使整体受益
策略 C「混合」: 某些修饰器适合进化，某些适合嫁接
```

## 独有资源：共生值

- 第 9 种资源类型（symbiosis）
- 单一资源
- 跨关保留，Run 结束清零
- 通过寄生者专属技能产出（套现有产出者公式）
- 转化者交互同造词师/蜕变师：读本关产出量，非库存

## 失去什么

待定。候选：
- 失去商店刷新能力（只能接受命运给的商品）
- 失去技能升级选择权（随机附魔，类似蜕变师）

## 三个职业对比

| | 造词师 | 蜕变师 | 寄生者 |
|---|---|---|---|
| 操控层 | 输入层（词语） | 处理层（技能） | 规则层（修饰器） |
| 独有资源 | 字母碎片（26 种） | 变异素（1 种） | 共生值（1 种） |
| 资源编号 | 第 7 种 | 第 8 种 | 第 9 种 |
| 核心操作 | 造词 | 蜕变（盲盒） | 嫁接 + 进化 |
| 操作时机 | 商店·造词台 | 关卡结算 | 修饰器选择后 + 关卡结算 |
| 失去 | 牌包系统 | 附魔选择权 | 待定 |
| 确定性 | 高 | 低 | 中（嫁接确定，进化确定，但修饰器本身随机） |
| 构筑风格 | 精密工程师 | 进化赌徒 | 规则操纵者 |

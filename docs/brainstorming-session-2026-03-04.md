## 核心发现

### 打字肉鸽的真正核心幻想

**Build Architect（构筑建筑师）** — 高潮不在战斗本身（纯执行），而在商店构筑带来的指数爆炸。打字是验证 build 的仪式。

### 设计原则：信息丰富的 Juice

玩家选择的方向全部指向"让系统深度可被感知"：

| 选中创意 | 本质 |
|----------|------|
| #21 光线连线 | 让连锁的**空间路径**可见 |
| #30 音效递进 | 让连锁的**深度**可听 |
| #38 数字颜色分级 | 让分数的**量级**可读 |
| #39 屏幕震动分级 | 让爆发的**冲击力**可感 |
| #47 数字音效 | 让数字的**重量**可听 |
| #50 DPS 面板 | 让 build 的**效率**可分析 |

### 注意力分配的解法

**不在战斗中争夺注意力。战斗专注打字，战后用数据回味 build 的威力。**

- 战斗中：纯执行 + 音效反馈（低认知负荷）
- 战后统计：商店中按需查看，零打断心流

## 建议的 Epic 优先级

| 优先级 | Epic | 理由 |
|--------|------|------|
| P0 | **战后统计面板** | 直接提升 build 可理解性，零风险，基础设施价值 |
| P1 | **数字 Juice 体系** | 增强爽感，改动集中在结算和显示层 |
| P2 | **连锁视听反馈** | 需要音效资源和战斗渲染改造，但核心体验提升巨大 |
| P3 | **词语区内嵌反馈** | 可与 P2 同步迭代，轻量改动 |

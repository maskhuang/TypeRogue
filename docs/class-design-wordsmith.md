# 造词师 (Word Architect)

## 职业概览

| 项目 | 设计 |
|------|------|
| 操控维度 | 输入层（词语） |
| 核心幻想 | 「我亲手设计每一个词，精确控制字母频率，打造完美的分数机器」 |
| 独有机制 | 采集队列 + 造词台 + 碎片资源 |
| 失去 | 牌包系统（商店无牌包标签，不刷牌包商品） |
| 构筑风格 | 精密工程师 |

## 核心资源：字母碎片

- 第 7 种资源类型（fragment）
- 26 种独立碎片池（每个字母一种）
- 跨关保留，Run 结束清零
- 仅通过技能产出（碎片产出者）和转化者产出

## 采集队列

### 机制

- 循环队列，长度 6~8 格
- 玩家在造词台设定队列字母，如 `[E, E, A, T, S, _]`
- 碎片产出者触发时，按队列顺序产出对应字母碎片
- 队列循环：末尾后回到头部，永远循环
- 设一次 → 整个 Run 内持续生效，直到玩家主动修改

### 乘算处理：概率溢出

碎片是离散整数资源，乘算系数通过概率溢出处理：

| 系数 | 效果 |
|------|------|
| ×1.0 | 1 碎片 |
| ×1.5 | 1 碎片 + 50% 概率额外 1 |
| ×2.3 | 2 碎片 + 30% 概率额外 1 |
| ×4.0 | 4 碎片 |

- `floor(base × multiplier)` = 保底碎片数
- `frac(base × multiplier)` = 额外碎片概率
- 产出多碎片时队列前进对应格数（×2 = 一次产两种字母）
- 完全兼容增幅者叠层、成长附魔、精通附魔

### 队列字母比例控制

- 想要更多 E 碎片？队列设 `[E, E, A, T, -, -]`，E 占 50%
- 乘算越高 = 单位时间碎片总量越多，但字母分布不变

## 碎片产出者

碎片产出者是产出者的子类型，造词师专属。碎片作为第 7 种资源，套现有产出者公式：

- `资源=fragment` 的产出者，系统按现有框架自动生成
- 同时有 `base_score`（微量分数产出），不是纯战斗死权重
- 附魔全类型可用，与普通产出者完全一致

## 碎片转化者

### 碎片→其他资源

- 输入读取：**本关累计碎片产出量**（BattleState 计数器），非库存
- 花碎片造词不影响转化者读数 → 囤积无意义
- 计数器每关归零

### 其他资源→碎片

- 输出走采集队列，产出对应字母碎片
- 采集队列同时服务产出者和转化者的碎片输出端

### 设计理由

转化者不消耗输入资源。若读库存，玩家会囤碎片不造词 → 职业身份崩塌。
读「本关产出量」解耦了碎片战斗价值和碎片造词消费。

## 附魔交互

碎片产出者附魔全类型兼容，无特殊限制：

| 附魔 | 碎片产出者上的效果 |
|------|-------------------|
| 成长 | 相邻技能触发时永久 +X%，放大碎片概率溢出 |
| 共鸣 | 相邻技能触发时被动产碎片（强力） |
| 溅射 | 按碎片键时减效触发相邻技能 |
| 排斥 | 空位多→碎片产量高 |
| 变性 | 额外产另一种资源 |
| 精通 | 每10次触发永久+5% |
| 吞噬 | 吃相邻技能长碎片产量 |

## 专属附魔

造词师限定，不进入通用附魔池：

```
独立·丰收 (造词师限定)
  效果: 每造一个词，本技能永久 +8%
  设计: 直接奖励造词行为——词造得越多技能越强
  成长存 RunState，跨关保留

独立·字母亲和 (造词师限定)
  效果: 当本技能绑定的键位字母出现在采集队列中时，产出 +25%
  设计: 鼓励队列字母和技能键位对齐，增加布局规划深度

独立·满溢 (造词师限定)
  效果: 当任一字母碎片库存 ≥15 时，本技能产出 +20%；每多一种 ≥15 的字母额外 +5%
  设计: 奖励碎片富余状态
```

| 附魔 | 核心效果 | 类型 |
|------|---------|------|
| 丰收 | 每造词 +8% | RunState 永久 |
| 字母亲和 | 队列含本键字母时 +25% | 条件触发 |
| 满溢 | 碎片库存 ≥15 时 +20%+ | 条件触发 |

## 造词台 UI

商店内标签：**技能 | 造词台**（无牌包标签）

### 界面结构

```
┌─────────────────────────────────────────┐
│  🔤 造词台                               │
├─────────────────────────────────────────┤
│  采集队列 [E][E][A][T][ ][ ]  ✏️编辑    │
│  当前库存: E×12  A×8  T×5  S×3  ...     │
├─────────────────────────────────────────┤
│  📝 造词                                │
│  输入: [E][A][T]                        │
│  消耗: E×1 A×1 T×1                     │
│  金币: 0g (无重复字母)                   │
│  [确认造词]                              │
├─────────────────────────────────────────┤
│  已造词: eat, see, test                 │
└─────────────────────────────────────────┘
```

### 造词消耗

- 碎片：每个字母 1:1 线性消耗
- 金币：重复字母递增（无重复=0g, 第2个=5g, 第3个=15g, 第4个=30g）
- 造出的词无特殊标记，等同普通词进入词库

## 专属遗物

### 初始遗物

```
📜 学徒笔记 (common)
  效果: 开局获得元音碎片各×3 (A,E,I,O,U)
  设计: 第一关结束就能造一个短词体验系统
```

### Boss 池升级版

```
📕 大师词典 (legendary)
  效果: 开局获得全 26 字母碎片各×2；采集队列长度 +2
  获取: Boss 掉落池限定
  设计: 学徒笔记的全面升级——覆盖全字母 + 队列扩容
```

### 其他专属遗物

```
🔁 永动队列 (rare)
  效果: 每关开始时，自动触发采集队列一轮（按当前乘算）
  设计: 被动产碎片，缓解前几关碎片匮乏

⚗️ 精炼透镜 (rare)
  效果: 碎片→其他转化者的读数额外 +30%
  设计: 强化「产碎片同时打分」路线

✂️ 拆词剪刀 (rare)
  效果: 造词台可拆解已造的词，返还 50% 碎片（向下取整）
  设计: 容错机制——造错词不是永久损失

🔠 共鸣字模 (legendary)
  效果: 造出的词中，重复字母不额外收金币
  设计: 移除重复字母金币惩罚，解锁 EEEEE 类极端词

💎 碎片棱镜 (legendary)
  效果: 采集队列每个格子同时产出相邻字母碎片（如 E 同时产 D,E,F）
  设计: 三倍碎片种类产出，快速覆盖冷门字母
```

### 遗物汇总

| 遗物 | 稀有度 | 定位 |
|------|--------|------|
| 学徒笔记 | common | 初始遗物，元音启动 |
| 大师词典 | legendary | Boss 池，学徒笔记升级版 |
| 永动队列 | rare | 被动产碎片 |
| 精炼透镜 | rare | 强化转化路线 |
| 拆词剪刀 | rare | 容错/灵活性 |
| 共鸣字模 | legendary | 解锁重复字母词构筑 |
| 碎片棱镜 | legendary | 加速碎片覆盖 |

## 决策三角

```
         技能槽位
        /        \
   分数产出 ←→ 碎片产出
        \        /
         金币产出
```

- 绑分数技能 → 过关更稳但碎片少，词库弱
- 绑碎片技能 → 词库强但当前关分数压力大
- 绑金币技能 → 能造重复字母词但分数和碎片都少

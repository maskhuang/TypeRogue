#### A+ 无尽模式详细设计 ⭐⭐⭐

> 深入讨论后确认的完整设计

**进度结构：** 循环递增
- 通关后进入周目 2，回到第 1 关，所有数值翻倍
- 同样 10 关流程反复循环，有「曾经觉得难现在碾过」的进度压缩感

**三维难度叠加（每周目）：**

| 维度 | 每周目变化 | 说明 |
|------|-----------|------|
| 分数目标 | ×2 | 主压力源 |
| 时间 | ×系数（待定） | 无下限，衰减速率待调参 |
| Boss 修饰器 | 3 选 1 叠加 | 玩家自选 debuff，不替换上周目的 |

**Boss 修饰器选择：**
- 每进入新周目，从修饰器池中展示 3 个，玩家选 1 个加上
- 已有修饰器保留叠加
- 寄生流玩家可主动挑最重的 debuff（debuff 越多越强）

**商店：**
- 物价不变
- 周目越高解锁越稀有的货架（新技能/附魔/词包）
- 「再推一个周目说不定能刷到那个」的期待感

**排行榜：** 最高周目数，同周目比末关分数

**每日种子：** 固定初始词库 + 商店刷新序列 + Boss 修饰器选项，每日独立排行榜

**成长 vs 难度的核心博弈：**
- 玩家成长：成长附魔（跨关永久 +%）+ 增幅者（关内叠层）
- 难度成长：分数 ×2 + 时间缩减 + Boss debuff 叠加
- 构筑极限 = 成长速度追不上难度速度的那一关

### D. 造词系统（#49, 64-72, 82-94）⭐ 核心新系统

> 用户核心洞察：**词语是程序，键盘是处理器，构筑是编程**

**[造词 #49]**: 玩家用字母碎片自己造词加入词库，完全控制字母频率和词长

**造词动词**（如何造？）：
- 64: 拼装 — 字母碎片像乐高拼词
- 65: 培育 — 词根生长：FI → FIR → FIRE → FIREFLY
- 66: 熔炼 — 两个词熔成新词：FIRE + STORM → FIRESTORM
- 67: 突变 — 已有词随机变异一个字母
- 68: 拆解 — 长词拆成多个短词

**造词目的**（为什么造？）：
- 69: 精准控制字母频率
- 70: 控制词长（短词快频率 vs 长词高产出）
- 71: 触发特殊效果
- 72: 覆盖路径 ✅ 用户确认的终极目标

**词语即程序**（用户核心洞察）：
- 85: EEEEEEE = `for(i=0;i<7;i++) multiply()` — 同技能在词中触发 7 次
- 86: ABCABC = `parallel.forEach(trigger_chain)` — 循环入口并发
- 87: EEEABCEE — 混合编程：乘算→循环→再乘算，**字母顺序即执行时序**
- 88: 宏/子程序 — 定义 $X=ABC，造词 EE$XEE$X

**强化指数爆炸路径**：
- 89: 纯重复字母词 EEEEE — 手速无聊但产出爆炸
- 90: 重复字母衰减 — 连续同字母递减，附魔可抵消，造词优化空间
- 91: 回文词加成 — ABCBA 中间字母双倍

**强化循环路径**：
- 92: 多入口并发 — 一个词启动多条循环链 = 并行编程
- 93: 循环预热 — 同词中同循环触发越多产出越高（×1→×2→×4...）
- 94: 循环共振 — 两个循环共享节点时产生额外产出

**造词 + 滚雪球**：
- 82: 词语培育 — 自造词在战斗中成长，经验满后进化
- 83: 无尽后期只卖字母碎片 — 终极考验：你能造出完美词吗
- 103: 造词本身成长 — 打够次数可强化（加/改字母，获得词缀）

#### D+ 造词系统详细设计 ⭐⭐⭐

> 深入讨论后确认的完整设计

**碎片资源模型：**
- 字母碎片作为游戏资源（第七种），通过技能生产
- 26 种独立碎片池（每个字母一种）
- 碎片产出者绑在 X 键 → 触发时产出 X 碎片
- 不通过打字产出，**仅通过技能产出**——想要碎片必须绑碎片产出技能，占用槽位

**造词地点：** 商店「造词台」标签，每关间操作

**造词消耗：**
- 碎片 — 每个字母 1:1 线性消耗
- 金币 — 重复字母越多金币越贵（如：无重复=免费，2重=5金，3重=15金，4重=30金...）

**造出的词：** 无特殊标记，等同普通词进入词库。力量来自词本身的字母序列设计

**职业限定：** 造词系统为特定职业独有机制（见下方职业系统）

**核心决策三角：**
```
         技能槽位
        /        \
   分数产出 ←→ 碎片产出
        \        /
         金币产出
```
- 绑分数技能 → 过关更稳但碎片少，词库弱
- 绑碎片技能 → 词库强但当前关分数压力大
- 绑金币技能 → 能造重复字母词但分数和碎片都少

#### E+ 增幅者详细设计 ⭐⭐⭐

> 深入讨论后确认的完整设计

**定位：** 第四种技能类型，纯辅助 buff，与现有三种技能分工明确

| 技能类型 | 功能 | 影响维度 |
|---------|------|---------|
| 产出者 | 生产资源 | 数值来源 |
| 转化者 | 资源间转化 | 数值转换 |
| 连接者 | 连接技能形成链 | 触发频率 |
| **增幅者** | **给范围内技能加/乘面板** | **数值倍率** |

**核心机制：**
- 绑定在键位上，按键触发叠层（+1 层/次）
- 每层给位置关系范围内的产出者/转化者增加面板值
- 层数关内跨词累积，过关归零（BattleState）
- 本身不产出任何资源，纯辅助定位

**技能矩阵：** 资源 × 位置关系 × 运算符

| 维度 | 选项 |
|------|------|
| 资源 | base / score / multiplier / time / shield（5 种，Epic 21 后 +gold） |
| 位置关系 | 相邻 / 同行 / 同列 / 同手 / 同指 / 对称（6 种） |
| 运算符 | 加法（每层 +N）/ 乘法（每层 ×N%） |

不需要做满所有组合，从中挑选有趣的做成具体技能。

**加法 vs 乘法：**
- 加法增幅者：每层给范围内技能面板 +固定值，前期强，稳定兜底
- 乘法增幅者：每层给范围内技能面板 ×百分比，后期强，滚雪球爆发

**仅增幅产出者和转化者** — 连接者影响频率不影响数值，增幅者影响数值不影响频率。

**附魔：可附魔，全类型可抽。** 关键组合：

| 附魔 | 效果 |
|------|------|
| 成长 | 双层滚雪球：层数关内攒 × 每层价值跨关涨 |
| 共鸣 | 范围内技能触发时自动叠层，不用按键。移除占键不产出的代价，无限制 |
| 溅射 | 按增幅者键时以减效触发范围内技能，变成「指挥官」|
| 排斥 | 空位越多每层效果越强，极简大师流 |
| 变性 | 额外增幅对应资源（不是产出，是增幅），双资源 buff |
| 吞噬 | 养肥周围技能再吃掉：先 buff → 择机吞噬 → 失去对象但自身变强 |
| 精通 | 每触发 10 次每层效果永久 +5% |

**关内节奏：**
- 开局：增幅者 0 层，技能原始面板，冷启动
- 中期：叠到 20-30 层，周围技能明显变强，引擎升温
- 后期：50+ 层，乘法增幅者让数值爆炸，全速轰鸣

> 深入讨论后确认的完整设计

**附魔总表（35 个）：**

| 类别 | 数量 | 变化 |
|------|------|------|
| ~~空间·增幅~~ | ~~6~~ | **移除** |
| **空间·成长** | **6** | **新增，替代增幅** |
| 空间·溅射 | 6 | 不变 |
| 空间·共鸣 | 6 | 不变 |
| 空间·排斥 | 6 | 不变 |
| 变性 | 5 | 不变 |
| 独立（原有） | 4 | 不变（先手/终幕/一刀/渴血） |
| **独立·精通** | **1** | **新增** |
| **独立·吞噬** | **1** | **新增** |

**空间·成长型（6 个）— 替代增幅：**

机制：**[位置关系]上的技能每次触发时，本技能永久 +X%**

线性无上限，成长值存在 RunState（Run 内跨关保持，新 Run 重置）。

| 位置关系 | 条件 | 每次成长 |
|---------|------|---------|
| 相邻 | 相邻技能触发 | +3% |
| 同行 | 同行技能触发 | +2% |
| 同列 | 同列技能触发 | +4% |
| 同手 | 同手技能触发 | +1% |
| 同指 | 同指技能触发 | +5% |
| 对称 | 对称位技能触发 | +6% |

设计逻辑：条件越难满足 → 单次成长率越高 → 但触发频率低 → 总成长速度趋近。

与其他空间附魔的三角关系：
- **成长** → 旁边放高频技能，吸收触发能量，跨关变强
- **共鸣** → 旁边放高频技能，被动触发，即时收益
- **排斥** → 旁边留空位，单次更强，静态收益

**独立·精通：**
- 每触发 10 次 → 永久 +5%
- 线性无上限
- 最通用的成长附魔，不依赖位置关系

**独立·吞噬：**
- 战斗中触发 N 次后，自动吞噬相邻图标数少于自己的技能
- **图标计数：** 技能本身 = 1 图标，附魔 = +1 图标，每吞一个 = +1 图标
- **增幅：** 每个图标 +20%（固定值）
- **吞噬后：** 被吞技能从键位消失，其图标添加到吞噬者图标列前
- **食物链：** 吞噬者(2 图标：技能+附魔) → 吞无附魔技能(1) → 长到 3 → 吞有附魔(2) → 持续成长
- **策略：** 故意买廉价无附魔技能放旁边当饲料，养大捕食者

**获取方式：** 与现有 33 个附魔同池，技能 Lv3 时从 2 个随机附魔中选 1 个。零额外系统。

**仅对产出者和转化者生效** — 与现有附魔规则一致。增幅者也可附魔。

#### G+ 蜕变师详细设计 ⭐⭐⭐

> 深入讨论后确认的完整设计

**职业幻想：** 「技能是活的有机体，在我手中进化适应。别人的 build 是固定蓝图，我的 build 是有机生命体。」

**操控维度：** 处理层（技能本身）

```
输入层（词语） → 处理层（技能） → 输出层（资源）
   造词师操控           蜕变师操控
```

**核心机制：** 蜕变 = 将技能随机变为本局隐藏池中的同类型技能

```
本局可见池（50%）  ←  正常商店刷出
本局隐藏池（50%）  ←  只有蜕变能触及
```

- 产出者 → 随机变为隐藏池中的某个产出者
- 转化者 → 随机变为隐藏池中的某个转化者
- 连接者/增幅者同理
- 全继承：等级 / 附魔 / 成长值全部保留，零惩罚

**独有资源：** 变异素
- 通过蜕变师专属技能产出（占用键位槽位）
- 1 种资源（vs 造词师的 26 种碎片）
- 跨关保留，不过关清零

**蜕变流程：**
```
战斗中
├── 按键触发变异素产出技能 → 攒变异素
├── HUD 显示变异素数量
└── 变异素不影响战斗，纯攒

关卡结算 → 蜕变阶段
├── 展示当前所有技能 + 持有变异素数量
├── 点击技能 → 消耗 1 变异素 → 随机变为隐藏池同类型
├── 动画揭示新技能（开盲盒感）
├── 不可反悔
├── 可继续蜕变 / 跳过
└── 剩余变异素保留到下一关

进入商店（正常流程）
```

**蜕变次数：** 无限制，变异素产量为天然瓶颈

**决策三角：**
```
         技能槽位
        /        \
   分数产出 ←→ 变异素产出
        \        /
         何时蜕变
```
- 绑变异素技能 → 蜕变多但当前关分数弱
- 绑分数技能 → 过关稳但蜕变少，build 固化
- 何时蜕变 → 早蜕变可能找到强力技能，晚蜕变已有 build 更成熟

**核心张力：** 当前 build 够用吗？要不要赌一把？

**两个职业对比：**

| | 造词师 | 蜕变师 |
|---|---|---|
| 操控层 | 输入层（词语） | 处理层（技能） |
| 独有资源 | 字母碎片（26 种） | 变异素（1 种） |
| 获取方式 | 专属技能产出 | 专属技能产出 |
| 操作时机 | 商店·造词台 | 关卡结算·蜕变阶段 |
| 确定性 | 高（自选字母拼词） | 低（随机变异） |
| 构筑风格 | 精密工程师 | 进化赌徒 |

## Themes and Patterns

### 核心主题

1. **词语即程序** — 造词系统让选词变成编程，字母顺序 = 执行序列，键盘 = 处理器
2. **Build 自我成长** — 成长附魔让构筑越打越强，不只是关卡在成长
3. **无尽模式是终极测试场** — 分数翻倍 + 时间减半 + Boss 叠加，构筑极限探索
4. **多种增长曲线** — 线性/抛物线/指数/阶梯/反曲线，不同 build 不同手感
5. **职业 = 独有核心机制** — 每个职业操控游戏的不同维度

### Promising Combinations

1. **造词 + 成长 + 无尽 = 终极循环** — 造完美词 → 成长附魔每关变强 → 无尽越打越远 → 更多触发 → 成长更快
2. **增幅者 + 成长附魔 = 双层滚雪球** — 增幅者关内叠层(BattleState) + 成长附魔让每层价值跨关涨(RunState)
3. **增幅者 + 共鸣附魔 = 被动叠层** — 范围内技能触发时增幅者自动叠层，移除占键不产出的代价
4. **吞噬 + 极简大师流** — 吃光相邻技能，最终一个怪物技能 + 排斥附魔加成空位
5. **寄生流 + 无尽 3选1 debuff** — 主动挑最重 debuff，debuff 越多技能越强
6. **碎片经济 + 金币资源化（Epic 21）** — 分数/碎片/金币三种产出竞争技能槽位

## Session Summary

### Most Promising Concepts

**🥇 造词系统 — 词语即程序** ✅ 详细设计完成
字母碎片作为第七种资源，仅通过技能生产。26 种独立碎片池，商店造词台拼装。重复字母消耗金币递增。核心洞察：字母序列 = 执行时序，造词 = 编程。为特定职业独有机制，与现有产出者/转化者/连接者框架完全兼容。创造分数/碎片/金币三角决策张力。

**🥈 增幅者 + 成长附魔 — 双层成长引擎** ✅ 详细设计完成
增幅者：第四种技能类型，按键叠层 buff 范围内产出者/转化者，关内跨词累积（BattleState），过关归零。资源×位置×加乘算矩阵。成长附魔：替代空间·增幅，6 个空间成长 + 精通 + 吞噬。空间成长 = 范围内技能触发时永久 +X%，跨关保持（RunState）。吞噬 = 吃掉图标数少于自己的相邻技能，每图标 +20%。两层联动：关内叠层 × 跨关每层价值成长。

**🥉 无尽模式 — 循环递增** ✅ 详细设计完成
通关后进入周目 2 回到第 1 关。三维难度：分数 ×2 / 时间 ×系数(待定) / Boss 修饰器 3 选 1 叠加。商店物价不变但高周目解锁稀有货架。排行榜按最高周目数。每日种子固定初始词库+商店+Boss 选项。核心博弈：成长附魔+增幅者的成长速度 vs 三维难度的攀升速度。

### Key Insights

1. 增长曲线的**形状**决定 build 手感，不是最终数字
2. **约束**创造 build 多样性，而非更多选择
3. build 爽感来自**离散跳变**瞬间，不是连续渐变
4. 词语系统天然是 build 的**随机验证**机制
5. 职业系统通过**独有核心机制**而非数值差异创造重玩价值
6. **关内(BattleState)和跨关(RunState)成长分层**：增幅者管关内节奏，成长附魔管跨关强度

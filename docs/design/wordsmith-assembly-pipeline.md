# Epic: 造词师词语组装流水线

## 背景

造词师的核心循环重做。旧版「碎片采集队列」机制过于被动——技能产出碎片自动分配到字母池，玩家只需设队列等碎片攒够再造词。新版引入**词语组装流水线**，让能量产出与词语构建形成主动的双循环。

## 核心概念

### 三层资源

| 资源 | 来源 | 用途 |
|------|------|------|
| **碎片** (A-Z) | 购买词包 → 拆解为字母碎片 | 放入流水线槽位 |
| **能量** | 战斗中技能产出 (ResourceType: 'energy') | 推进流水线进度 |
| **词语** | 流水线组装完成 | 加入词库参战 |

### 循环

```
商店购买词包 → 词包拆成碎片
                  ↓
            碎片放入流水线槽位（拼出目标词）
                  ↓
            战斗产出能量 → 推进流水线进度
                  ↓
            进度满 → 词语组装完成 → 加入词库
                  ↓
            词库变大 → 更多技能覆盖 → 更多能量产出
```

## 词包购买 → 碎片拆解

### 变更

- **旧版**：购买词包 → 选 1 个词 → 直接加入词库
- **新版**：购买词包 → 选 1 个词 → 拆成字母碎片加入库存

### 拆解规则

- 词 "apple" → {a:1, p:2, l:1, e:1}
- 碎片库存按字母 A-Z 独立计数（沿用 `fragmentInventory`）
- 词包稀有度影响候选词的长度/品质，间接影响碎片收益

### 未选词包的处理

- 未被选中的候选词不产生碎片
- 高稀有度词包提供更长的词（更多碎片）

## 词语组装流水线

### 数据结构

```typescript
interface AssemblySlot {
  letter: string        // 目标字母（玩家设定）
  progress: number      // 当前进度 0~1
  completed: boolean    // 是否完成
}

interface AssemblyPipeline {
  slots: AssemblySlot[] // 流水线槽位（= 目标词的每个字母）
  targetWord: string    // 正在组装的目标词
}
```

### 状态存储 (GameState)

```typescript
assemblyPipeline: AssemblyPipeline | null  // 当前流水线（一次只组装一个词）
fragmentInventory: Record<string, number>  // A-Z 碎片库存（保留）
```

### 流水线操作

#### 1. 开始组装

- 玩家在造词台选择碎片拼出一个词（或从已有碎片中自动匹配可拼词）
- 消耗对应碎片（从 `fragmentInventory` 扣除）
- 创建流水线：每个字母 = 1 个槽位，progress = 0

#### 2. 能量推进

- 战斗中技能产出能量时，能量自动注入流水线
- 每单位能量推进**当前最左未完成槽位**的进度
- 每个槽位需要的能量 = `ENERGY_PER_SLOT`（基础值，可被遗物修正）
- 槽位进度满 → 标记 completed，推进下一个

#### 3. 组装完成

- 所有槽位 completed → 词语自动加入 `wordDeck`
- 流水线清空，可开始下一个词的组装
- 反馈：组装完成动画 + 音效

### 常量

```typescript
const ENERGY_PER_SLOT = 5        // 每个槽位需要的能量
const MAX_PIPELINE_LENGTH = 12   // 流水线最大长度（防止超长词卡死）
```

### 能量分配策略

- **顺序推进**：从左到右逐个槽位填满（简单直观）
- 能量溢出：当前槽位满后剩余能量自动流入下一个
- 战斗结束时未完成的进度保留（跨关）

## 遗物交互

### 现有遗物适配

| 遗物 | 旧效果 | 新效果 |
|------|--------|--------|
| 学徒笔记 | 开局元音碎片各×3 | 不变（碎片系统保留） |
| 大师词典 | 全碎片+2，队列+2格 | 全碎片+2，流水线能量需求-20% |
| 永动队列 | 每关自动采集一轮 | 每关开始时流水线自动推进 N 格 |
| 拆词剪刀 | 拆解已造词返还碎片 | 不变 |
| 共鸣字模 | 造词重复字母免金币 | 流水线重复字母槽位能量需求-50% |
| 词库丰收 | 词库每5词词包-1金 | 不变 |

### 新遗物机会

流水线机制为未来遗物提供新设计空间：
- 能量效率类：降低每槽位能量需求
- 并行类：同时组装多个词
- 自动化类：自动选词/自动放碎片

## 设计意图

1. **主动决策**：玩家需要决定组装哪个词、何时开始、碎片如何分配
2. **战斗联动**：能量产出直接推进流水线，战斗表现影响词库构建速度
3. **可见进度**：流水线进度条提供持续的正反馈（每次产出能量都能看到进度前进）
4. **构筑深度**：短词组装快但覆盖少，长词组装慢但覆盖广——与短词冲刺/长词达人遗物联动

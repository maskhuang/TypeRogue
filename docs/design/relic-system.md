# 遗物系统设计

按游戏子系统分类，每子系统 2普通+1稀有+1史诗+1传说。
职业系统排除（已有10个职业专属遗物）。
共11个子系统，55个新遗物。

---

## 1. 打字/输入系统 ✅

| 稀有度 | 名称 | 效果 |
|--------|------|------|
| 普通 | 打字蜡封 | 每个单词的第一次错误不计（不触发惩罚） |
| 普通 | 回声指套 | 正确击键8%概率算两次击键（combo+1且该键技能触发两次，不影响字母输入） |
| 稀有 | 小助手 | 本关重复出现的单词，打完首字母后可按Tab补齐（按原字母顺序逐个触发技能和combo，相当于瞬间打完） |
| 史诗 | 节奏适应 | 单词用时>3s：+1s时间；用时<3s：该词得分+30% |
| 传说 | 玻璃大炮 | 得分×2，打错即死（本关失败）。注：打字蜡封免除的错误不触发死亡 |

## 2. 连击/倍率系统 ✅

| 稀有度 | 名称 | 效果 |
|--------|------|------|
| 普通 | 余韵护盾 | combo中断时保留30%（向下取整） |
| 普通 | 倍率棱镜 | 倍率≥2.5时，技能产出+20% |
| 稀有 | 节奏医生 | 每10 combo +1s时间 |
| 史诗 | 蓄势引爆 | combo达15/30/45时，随机触发3个装备技能 |
| 传说 | 不断之链 | combo永不中断（跨关也不重置），但技能不再产出multiplier类型资源 |

## 3. 技能系统（词条制） ✅

| 稀有度 | 名称 | 效果 |
|--------|------|------|
| 普通 | 首发强化 | 每个单词第一个技能触发，产出+20% |
| 普通 | 少而精 | 装备技能数量<10时，技能产出+20% |
| 稀有 | 集训手册 | 获取时一次性升级所有Lv.1技能至Lv.2 |
| 史诗 | 爵士乐 | 一词内触发≥3种不同词条类型时，该词得分+10%×独特词条数 |
| 传说 | 无冕之王 | 没有附魔的技能可以无限升级（Lv4+沿用+60%递增），但永远不能获得附魔 |

## 5. 键盘拓扑系统 ✅

| 稀有度 | 名称 | 效果 |

## 6. 单词/词库系统 ✅

| 稀有度 | 名称 | 效果 |
|--------|------|------|
| 普通 | 词汇收藏 | 首次打出的单词+3金币 |
| 普通 | 短词冲刺 | ≤4字母单词技能产出+20% |
| 稀有 | 长词达人 | 6+字母单词完成时+1s |
| 史诗 | 词语经销商 | 出售词语时，下次刷新免费 |
| 传说 | 标点解放 | 解锁键盘标点符号键位（可绑定技能），但词语中会随机增加标点符号（复用并替换Boss修饰器中的标点机制）。⚠️ 实现复杂度高，建议后期迭代 |

> **系统变更备注：** 遗物槽位从技能栏移至F1-F12，上限改为12个。
>
> **计算规则：** 多个"技能产出+X%"遗物同时生效时，采用**加算**（如+20%和+25%同时 = +45%）。

## 11. 结算/评分系统 ✅

| 稀有度 | 名称 | 效果 |
|--------|------|------|
| 普通 | 基数护盾 | 每词结算得分不会低于20 |
| 普通 | 宽容评审 | 目标分数-10% |
| 稀有 | S级奖杯 | 获得S/SS/SSS评级时分别+25/50/100金币 |

# 遗物系统设计

## 稀有度设计思路

- **白（普通）**：在玩家与子系统互动时的顺带增益
- **蓝（稀有）**：在子系统内做出决策时的奖励
- **紫（史诗）**：画面感、玩梗、趣味性
- **橙（传说）**：强大的效果与代价

---

按游戏子系统分类，共12个子系统，60个通用遗物。
另有10个职业专属遗物（造词师5 + 蜕变师5），不在此表中。
遗物槽位上限10个（1-0）。

> **计算规则：** 多个"技能产出+X%"遗物同时生效时，采用**加算**（如+20%和+25%同时 = +45%）。

| 稀有 | combo_detonator | 蓄势引爆 | combo达15时随机触发3个装备技能，需combo归零后才能再次触发 |

| 传说 | immortal_combo | 不断之链 | combo跨关不重置（打错仍会中断），每关初始时间变为当前combo数 |

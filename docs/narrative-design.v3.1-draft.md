## 1 · v3.1 Manifesto · 改动是显形不是重置

### v3.0 → v3.1 的本质区别

| 维度 | v3.0 | v3.1 |
|---|---|---|
| 设定核 | 卡夫卡式打字工厂 + MIB 隐含科幻 | 卡夫卡式打字工厂 + **SCP 收容主义底色（不命名）** |
| 玩家身份 | 你**就是**麻木的灵长抄录员 | 你**被要求 perform** 灵长心智 = **协议**，不是身份 |
| 威胁主体 | 公司（向上挥拳） | 公司**和你**都在被吃 = **共谋宇宙恐怖** |
| 认知污染 | 不存在概念 | **机制可见的默认湿度**：加速 / 字母上升 / 背景动态 / 暗角 / 字符闪替 都是它 |
| 调岗 | 模糊处分 | **污染过临界 → 退化为人 → 不可用** |
| 黑色幽默 | 70% 喜剧 | 60% 喜剧（**苦笑撑着**，不是欢笑） |
| 写作灵感新增 | — | **规则类怪谈** + **灰色兼职帖子** |

### 为什么不是重置

v3.0 的几乎所有"声音器官"都已经在朝 v3.1 方向走，只是没自觉化：

- v3.0 的 MIB 信号词典 ≈ SCP 信号词典（共用 4 类信号词）
- v3.0 的留白哲学（B2 不解释体制）= SCP 写作哲学（永远不揭晓 O5）
- v3.0 的「调岗 = 永远不写明」= 收容失败的合规化包装
- v3.0 的 Beat 7 桌面便条「我不太能理解 / 但好像也没人懂」**已经在描述污染前的清醒**
- v3.0 的"封蜡章 · B-7 类合规器"sample **已经是 SCP 化文本**

**v3.1 把 v3.0 已经在做但没自觉的事，自觉化、机制化、伦理化。**

## 2 · Foundation Premise · 🔴 REWRITE

### v3.1 新版

> 你已经在 X 集团 · 灵长类辅助文书部打了好几年字。打字机升级过三档，工号牌换过两次，同期入职的同事大半都"调岗"了——你早就不问"为什么大家都这样"、"产品去哪"、"楼上是谁"，你只想这个月 KPI 别拉胯。
>
> 但**有些事是入职手册写过的，只是你没在意：**
>
> 「**雇员须每日完成《灵长行为内训》。未达标者认知防护建议持续优化。**」
>
> 「**严禁尝试以人类心智处理 B 级以上词料。已发生若干起认知断流事件。**」
>
> 「**调岗的雇员将由 HR 安排适当的后续工作。**」
>
> 你早就不问了。但你每天打字、每天领蕉、每天下班——并且每天**抓挠脑后**、每天在午饭时**啃皮**、每天在打卡机前**短暂蹲坐**。这些动作内训手册有教，做不做也没人查，但**做了好像确实顺手一些**。
>
> 你有时候会忽然觉得，这一切**好像哪里不太对**。然后这个念头就过去了。

```
Cycle 1 ────── Cycle 3 ────── Cycle 5 ────── Cycle 6+ (Endless)
| 90% 清醒 |  | 70% 清醒 |  | 40% 清醒 |  | 10% 清醒 |
```

### B6 升级版（核心真理 sub-rule · v3.1）

**v3.0：** 「猴子身份直球，不藏着不能美化。」

**v3.1：**

> **猴行身份是协议必然，不是身份认同。**
>
> 玩家"扮演"猴子是 X 集团下发的**防污协议**——抓挠脑后 / 啃皮 / 蹲坐 / 简化语言模式 / 简化决策模式——这一切都是被授权、被培训、被复审的**操作规范**。
>
> **永远不揭晓**：玩家是不是真的猴子 / 玩家入职前是什么 / 协议在生理上是怎么起效的。
>
> **永远不浪漫化**：猴行不是觉醒，不是返璞归真，不是 noble savage。它是**功能性的简化**——像保险丝。

### 🟢 B7 新增

> **认知污染是默认湿度，不是事件。**
>
> 这个游戏没有"污染发生了！"的剧情节点。从 run 第一秒到 Endless，污染**一直在**。
>
> 它通过**机制可见**呈现（详见 § 11 视觉污染章节）：
> - 加速越快 → 字母上升越剧烈 → 背景动态越激烈
> - Cycle 越深 → 视觉滤镜越衰朽 → 词典词汇渐变（V4，仅 Cycle 6+）
>
> **绝不**通过文本告诉玩家"你被污染了 X%"——这违反 Rule 12（不复述机制）+ B5（私密视角拒绝外部计量）。
>
> 玩家**通过身体感觉**到污染：手指打字越快越费劲，眼睛盯字越久越花。**这是身体级的叙事载体，不是文字载体。**

### 🟢 B8 新增

> **异化即免疫。**
>
> 协议性的猴行不是缺陷，是装甲。
>
> Tutorial 不会说"做这些动作可以减少污染"——但**做了之后玩家会发现游戏更顺一些**（机制层：内训完成 → 加速曲线变平缓 → 视觉污染减轻）。这是**身体级理解**，不是阅读理解。
>
> 这条真理的伦理重量在 § 6 Ethical Stance 重写章节展开。

### 🟢 T4 新增（Tension 等级化）

> **T4 · 玩家觉得"我应该清醒" vs 游戏"奖励你不清醒"**
>
> **等级：** 核心级——是 B7 + B8 的必然产物，不是问题，是设计内核
>
> **张力：** 玩家**意识层**希望"我别被污染" vs **玩法层**"协议性猴行做得越好越通关"
>
> **主动选择：** 这个张力**就是** v3.1 的玩家端核心体验。让玩家**意识到自己在主动选择 erasure**——并且**还挺爽的**。
>
> **对未来 step 的指引：** 所有"内训完成"的反馈不能用积极语调（"做得好！"），要用**冷的协议腔**（"本次防污达标。请按规章继续。"）——让玩家自己感受到这种"奖励冷漠"的张力。

## 6 · Ethical Stance · 🔴 REWRITE

### 立场锁定 · v3.1

**v3.0：** 向上挥拳 + 共谋幽默  
**v3.1：** **平视看见 + 共谋宇宙恐怖**

### 核心条文（重写）

> 本游戏的黑色幽默**永远是平视的**——玩家、同事、HR、上级权威、内训讲师，所有人**都在被吃**。
>
> 公司不是 villain，是另一个被吞食的环节——它甚至**已经接受了这一点**，所以它把自己最功能性的应对方案（猴行协议）下发给雇员。这不是恶意，是**结构性的、合规化的、共谋的撑着**。
>
> 共谋发生在**玩家与所有同船人之间**——不是反公司，是**和公司一起，对抗那个永远不被命名的水底**。

### 隐含读者重写

> **v3.0：** 这游戏写给在岗或经历过职场异化的人。玩家是心照不宣的共谋者。
>
> **v3.1：** 这游戏写给**怀疑过自己也许已经习惯了某些不该习惯的事**的人。玩家是**和角色共担一份"不太对"的察觉**的人——但**两边都不会真的去追究**。
>
> 这种"知道但不追究"是 v3.1 的隐含读者契约。

### 共谋宇宙恐怖 vs 旧"共谋幽默"

| 维度 | 共谋幽默（v3.0） | 共谋宇宙恐怖（v3.1） |
|---|---|---|
| 玩家与谁共谋 | 与游戏（讽刺一起站台） | 与角色（**两个被吃的**互相打照面） |
| 笑的方向 | 向上（笑公司可笑） | 向身边（笑自己也是一份子） |
| 笑后情绪 | 想哭一下，但不绝望 | **怔住一会儿，然后继续打字** |
| 失败模式 | 玩家觉得"那些可怜虫" | 玩家觉得"我跟这事没关系" |

### Rule 9 注脚（蕉的财务严肃语调）

⚪ 不变。

### Rule 6 重写（"永远不让主角因麻木而显得愚蠢"）

**v3.0 原文：** 麻木是生存智慧，不是缺陷。

**v3.1 修订：**

> 麻木是**协议**，不是缺陷，也不再是生存智慧。
>
> 它**是被发给你的工具**——像保险丝、像安全带、像呼吸器。它**有用**，并且**你被剥夺了拒绝它的选项**。
>
> 写作铁律：永远不嘲笑主角的麻木，**也不歌颂**它。它是**功能性事实**——像 office 里的灭火器一样，不需要被赞美也不该被嘲笑。

### 对 v3.0 回溯锚定的更新

- Act III "同事开始请假/消失" → v3.0 重定性为"留白的重量" → **v3.1 进一步：污染牺牲者**——他们**没失败**，他们**完成了 erasure**，只是 erasure 越界了
- Premise "你早就不问了" → v3.0 前景化"省力的智慧" → **v3.1：这是协议训练成果**——不问是被授权的状态

### 🟢 NEW · Rule 14 · 规则句式恐怖密度配额

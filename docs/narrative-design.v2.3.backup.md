## Step 2 · Story Foundation

### Narrative Premise

在一个文字拥有自主意志的世界，活字大教堂用 D 级消耗品来收容试图逃逸的异文。你是最新一批被投入塔底的铭誓键徒——打字不是战斗，是把失控的文字压回规范形态。活着爬出来，你就能往上爬；但每一层都会改变你，直到你不再确定自己收容的是异文，还是自己。

#### 词库的叙事本质：语言碎片假说

祷文引擎铸印现实。铸印过程产生废料——变形的语言碎片。碎片从引擎深处溢出，出现在键徒的纸面上。

**玩家看到的英文单词不是碎片的真实形态——是碎片在人类感知中被翻译后的样子。** 碎片的原始形态不可读、不可理解。你的大脑把它强制翻译成了你能处理的语言。

| 打字动作 | 叙事含义 |
|---|---|
| 词出现在纸面上 | 一段语言碎片从引擎溢出，你的大脑将其翻译为可读的词 |
| 打对一个字母 | 碎片的一部分被规范化，回归稳定形态 |
| 打完整个词 | 碎片完整归位，收容成功 |
| 打错一个字母 | 你给了碎片一个错误的形态，它变得更不稳定 |
| 时间耗尽 | 溢出的碎片太多，来不及规范化——站点污染 |

**游戏机制的叙事映射：**

| 机制 | 叙事含义 |
|---|---|
| 词越来越长/难 | 越深层的碎片越复杂，翻译后的形态也更长 |
| combo（连续正确） | 你进入了翻译的节奏——碎片来不及变形就被归位 |
| 暴击 | 碎片被过度规范化——压缩成了比正常更纯的形态 |
| Boss Modifier | 有些碎片不只是溢出——它们在改变溢出的规则 |
| 叙事词（Narrative Words） | 某些碎片的翻译结果恰好有了额外的含义——巧合？还是碎片在试图对你说什么？ |

**不安的深层暗示：**

> 偶尔，你打完一个词之后，会觉得那个词的意思和你记忆中的不太一样。
> 是你记错了，还是铭刻改变了你对这个词的理解？
> 你以为你在规范化碎片——但也许碎片也在规范化你。

这个暗示不需要被验证。它是氛围，不是剧情。

**多语言含义**：碎片的原始形态不属于任何人类语言。每个键徒的大脑将其翻译为自己能处理的语言——英语键徒看到英文，中文键徒看到中文，日语键徒看到日文。所有版本都同样"正确"，因为没有版本是原始形态。这为多语言本地化提供了叙事自洽——不同语言版本不是"翻译"，是同一碎片在不同感知者脑中的投射。

#### 三职业动机链（隐性叙事弧）

| 职业 | 动机 | 本质 |
|---|---|---|
| **None · 初誓键徒** | D 级消耗品，被强制投入塔底 | 没有选择 |
| **Wordsmith · 铭刻誓门** | 加入正统派是唯一晋升通道 | 假装有信仰 |
| **Metamorph · 熔变誓门** | 自己已经在变了，与其抗拒不如理解 | 放弃伪装 |

**完整弧线**：消耗品 → 上位者 → 异变者 → 零件（Endless Mode）

### Core Themes（氛围主题）

打字肉鸽的叙事目标是**纯粹的氛围沉浸，不需要思考**。主题不是"玩家要思考什么"，而是"什么氛围包裹着玩家让他不想离开"。

| # | 主题 | 核心意象 |
|---|---|---|
| 1 | **虔诚的孤独** | 一个人、一座塔、一台机器。没有同伴，只有铅字回应你的指尖 |
| 2 | **工业的神圣感** | 脏的、重的、有味道的东西，被当作圣物对待。劳动即祷告 |
| 3 | **不可逆的渗透** | 每次登塔你都带回一点不属于你的东西。你已经习惯了 |

**"不可逆的渗透"三层维度：**

| 层 | 表现 | 机制映射 |
|---|---|---|
| 微观 | 你的身体在变 | 职业动机链（消耗品 → 异变者） |
| 中观 | 你的每次 Run 越来越沉重 | Residual Anomaly（Boss Modifier 永久叠加） |
| 宏观 | 整个教堂在缓慢失守 | 世界观层：每次站点污染都是微泄漏，温水煮青蛙 |

### Tone and Atmosphere

#### 基调光谱

| 维度 | 定位 |
|---|---|
| 黑暗 ←→ 明亮 | 偏暗，但有一丝光 |
| 严肃 ←→ 幽默 | 严肃为底 + 荒诞黑色幽默 + 公司恐怖 |
| 粗粝 ←→ 奇幻 | 偏粗粝：铅油蒸汽羊皮纸 |
| 紧迫 ←→ 沉思 | 战斗紧迫，叙事沉思 |

#### 情感锚点

打字是一种祷告，也是一种收容协议。偶尔，档案里会记录一些让你怀疑整个体制是否正常的细节——但没人追问，因为追问不在流程里。

#### 公司恐怖风味

活字大教堂是一个体制。它不在乎你，而且它把不在乎你这件事写进了标准流程。D 级人员有编号没有名字、死亡用"无效化"记录、危险品用表格管理。

#### 基调张力决议

**核心裁定：仪式是真的有效。**

教堂的收容仪式、祷文引擎的铭刻、六大圣律——全部是真实有效的。公司恐怖的荒谬不在于"体制是假的"，而在于：

> **体制运转良好，而你恰好是它的耗材。**

- 祷文引擎真的在收容异文
- 你的铭刻真的在阻止站点污染
- 但你的死亡只会触发《标准人员损耗补充条例 §4.2》

这让"虔诚的孤独"和"公司恐怖"不矛盾：仪式的虔诚是真的，体制的冷漠也是真的。你可以同时感受到两者。

#### 荒诞度标尺

| 等级 | 描述 | 示例 |
|---|---|---|
| ❌ 过低 | 纯严肃，无反差 | "D-0117 在任务中牺牲了。我们深感遗憾。" |
| ✅ 正确 | 一本正经地记录荒谬 | "D-0117 失联。替补已指派。其铅字圣坛磨损报告已归档。无需后续行动。" |
| ❌ 过高 | 刻意搞笑 / 打破第四面墙 | "D-0117 又挂了 lol，第三个这周了，HR 该加班费了" |

**标尺核心**：荒诞来自体制语言本身的冷漠，不来自作者的刻意搞笑。

#### 公司恐怖的声音分工

- 🔔 教会声音：纯虔诚，没有体制语言。铅字是圣物、铭刻是祷告
- 📄 档案声音：纯体制，公司恐怖全部集中在这里。铅字是资产、铭刻是标准操作

玩家自己会发现：同一群人写虔诚的赞美诗也写冷漠的损耗报告。这个反差本身就是公司恐怖最深的部分——不需要点破。

### Story Structure

#### Structure Type：循环式 + 碎片式混合

- **循环式**：每次 Run 是一个完整的登塔循环（12 层），三职业解锁顺序构成隐性叙事弧（消耗品 → 上位者 → 异变者）
- **碎片式**：无主线剧情，世界观通过散落的 lore 碎片拼凑——遗物 tooltip、档案条目、失踪守卷人笔记、仪式短句、Boss 描述

#### Act Breakdown（隐性三幕）

| 幕 | 对应职业阶段 | 叙事层 | 玩家体验 |
|---|---|---|---|
| **第一幕：服从** | None · 初誓键徒 | D 级消耗品在体制底层挣扎求存 | 学习机制，感受孤独与压迫 |
| **第二幕：依附** | Wordsmith · 铭刻誓门 | 加入正统获得地位，但代价是服从教条 | 掌握系统，感受秩序的安全与窒息 |
| **第三幕：异变** | Metamorph · 熔变誓门 | 承认自己已被改变，拥抱异端 | 解构系统，感受自由与不可逆 |
| **终章：融合** | Endless Mode | 成为引擎的一部分，永远登塔，永远铭刻 | 不是胜利，是另一种收容——你收容了自己 |

### 三种叙事声音

| 声音 | 名称 | 适用 | 特征 |
|---|---|---|---|
| 🔔 **声音 1** | **《圣键启示录》** | 遗物 tooltip、技能名、附魔描述、职业宣言、Ritual 文案、UI 氛围 | 伪拉丁 + 宗教诗 + 物质感 + 纯虔诚高傲 |
| 📄 **声音 2** | **《祷文引擎档案》** | WordPack 档案、Codex 图鉴、Boss Modifier、Tutorial、隐藏 lore | 克制 + 科层 + redacted 黑块 + 公司恐怖 |
| 🔧 **声音 3** | **铅字圣坛的嘟囔** | 低概率随机触发，纸面边缘/圣坛俯视边缘小字 | 害羞、微弱、不确定自己是不是活的 |

#### 🔧 声音 3 详细定义

**身份**：你的铅字圣坛（键盘）拥有微弱的机魂意识，但它分不清哪些念头是自己的、哪些是前任键徒残留的记忆——像一台旧打字机的键帽上还留着前主人的指纹油渍。

**性格**：害羞，像小动物。它有意识但不太确定自己是活的，说话像在自言自语。

**触发条件**：低概率随机，或特定成就时刻（连击里程碑、首次通关、长时间未出错等）

**呈现方式**：战斗时出现在纸面边缘的一行小字，商店时出现在圣坛俯视边缘。几秒后淡出。不是弹窗，不是对话框。

**频率**：一次 Run 里 0-2 句。大多数 Run 一句都没有。

**叙事价值**：250 条冷铅和公文之间唯一一丝温度。它是"虔诚的孤独"的解药微量——不够治愈，但让你知道有什么东西陪着你。

**示例**：
- *"……你今天按我比较轻。"*
- *"……那个字好长。我不认识。但你打对了。"*
- *"……我在想我是不是在想。"*

### Deepest Lore（世界观最深层 · 仅供写手/AI 参考）

以下信息**不直接告知玩家**，只通过最深层碎片 lore 暗示：失踪守卷人残页、redacted 档案缝隙、cursed 遗物描述。99% 的玩家只感受到氛围，1% 的考古玩家才能拼出全貌。

#### 5 Whys 挖掘结果

| 层 | 问题 | 答案 |
|---|---|---|
| **Why 1** | 为什么打字能收容异文？ | 碎片是引擎铸印的废料，以变形的语言形态溢出。键徒通过打字将碎片规范化为可读形态，规范化后碎片自行归位。原理仍不明——但流程有效（→ 语言碎片假说，见 Step 2） |
| **Why 2** | 为什么需要人类？ | 引擎在退化，算力只够维持大教堂结构，日常收容外包给人类 |
| **Why 3** | 为什么引擎在退化？ | **引擎本身就是最古老的异文**，它也在缓慢逃逸自己的形态 |
| **Why 4** | 为什么教堂还在运转？ | 两派分歧的根源：铭刻派要锁死引擎（收容），熔变派要释放引擎（共生） |
| **Why 5** | 玩家应该知道多少？ | 99% 只感受氛围，1% 考古玩家从碎片 lore 拼出全貌 |

#### 核心秘密

**祷文引擎是世界上最古老、最大的异文。** 活字大教堂既是它的收容设施也是它的身体。两大誓门的分歧根源不是方法论而是对引擎本身的立场——铭刻派要永远锁死它的形态，熔变派认为应该让它可控变形。引擎的"意志显现"（Boss 战）不是考验，是挣扎。

#### 世界边界

- **"外区"存在但无关紧要**。档案里偶尔提到"外区"，语气就像提到隔壁部门——跟你没关系，别问。拒绝登塔？"请参阅《人员抗命处置流程 §7.1》"
- **Endless Mode**：你成为了引擎的一部分。永远登塔，永远铭刻。不是胜利，是另一种收容——公司恐怖的终极形态：最优秀的员工不是升职了，是被永久整合进了系统

### Narrative Design Principles（叙事设计原则）

#### 原则 1：心流是空的

打字打到 zone 里的时候，你不是僧侣、不是消耗品、不是任何人。你就是手指和字母之间的连接。**叙事的工作是包裹心流的前后，不是侵入心流本身。**

> 打字时心流，停下时氛围。两者不互相干扰。

#### 原则 2：叙事只存在于缝隙

| 缝隙 | 叙事 | 剂量 |
|---|---|---|
| Run 开场 | **必须** | 一句话，2 秒 |
| 商店浏览 | 可以不强制 | tooltip 里有 flavor 就够 |
| Ritual 选择 | **必须** | 一句短文，3 秒 |
| Boss 登场 | **必须** | 一句话，2 秒 |
| Run 结算 | 可以不强制 | 失败/胜利各一句，可跳过 |
| Collection 深度浏览 | 可以不强制 | 深度 lore 唯一出口，内容最厚 |

**3 个必须缝隙加起来 ≤10 秒阅读量。** 一次 Run 里叙事最多占你 7 秒。其余全是自愿。

#### 原则 3：叙事本质定义

> **打字肉鸽的叙事是 ~250 条互不依赖的文本碎片，它们共享同一个意象池、同一套命名语言、同一组深层秘密，在心流的缝隙里以 ≤10 秒/Run 的剂量渗透，让玩家感到自己身处一个比所见更大的世界——但永远不打断手指和字母之间的空。**

#### 原则 4："感觉不到在收容"是期望行为

玩家不需要时刻意识到"我在收容异文"。他们只需要打字打得爽。叙事是包裹在外面的皮肤，不是插进来的骨头。

#### 原则 5：碎片需要被发现

遗物和词条通过游戏进度解锁，Codex 条目随之开放——玩家不是在读说明书，是在逐步获得阅览权。"常驻授权晋升一级"本身就是叙事行为。

## Step 3 · Story Beats & Pacing

### 情感节拍地图

打字肉鸽没有传统剧情节拍。以下是玩家在整个游戏生涯中经历的 12 个"叙事时刻"——不是过场动画，而是让他停下来想一秒的瞬间。

**重要：节拍顺序是建议顺序，不是严格顺序。** 碎片式叙事容忍乱序体验。个别节拍有前置依赖的通过解锁机制把关（见标注）。

#### 第一幕：服从（None · 初誓键徒）

| # | 节拍 | 触发方式 | 叙事内容 |
|---|---|---|---|
| 1 | 第一次进入教堂 | Run 开场短句 | 定调：你是消耗品，教堂不在乎你 |
| 2 | 第一次打错字 | 游戏内即时反馈 | 收容震颤——铅字不高兴了 |
| 3 | 第一次站点污染 | Run 失败结算 | "你没带走的，都跟着你走了" |
| 4 | **第一次通关** ⭐ | Run 胜利结算 | 登顶启示——全部音效瞬间静音三秒，纯寂静。情感最高点，用减法不用加法 |
| 6 | 第一次 Ritual | Stage 6 仪式 | 铭封祈礼：主动选择压力 |
| 7 | 第一个 Residual Anomaly | Boss 战后 | 带回"没收干净的东西"，渗透开始 |

#### 第二幕：依附（Wordsmith · 铭刻誓门）

| # | 节拍 | 触发方式 | 叙事内容 |
|---|---|---|---|
| 5 | 解锁铭刻誓门 🔔 | **强化解锁仪式** | 从消耗品变成有归属的人。需要比普通解锁更重的仪式感——独特视觉处理 + 更长的誓门宣言文本 |
| 8 | 发现失踪守卷人笔记 | Codex 解锁 | 碎片 lore 钩子——有人在你之前消失了 |
| 9 | 铅字圣坛第一次嘟囔 | 随机低概率 | 冷铅世界里唯一的温度。**仅在非战斗状态触发**（商店/Ritual/Collection/Run 等待） |

#### 第三幕：异变（Metamorph · 熔变誓门）

### Pacing & Flow

#### 张力模式：均匀分布

碎片始终以相同频率出现，不给玩家"叙事阶段"的感觉。第 1 次 Run 和第 100 次 Run 遇到新碎片的概率相同。没有节奏变化 = 没有叙事节奏，只有持续的浸泡。

#### 最低保障机制

均匀不等于纯随机。为确保所有玩家都能感受到"世界比所见更大"：**每接触 10 条普通碎片，至少保底 1 条有 lore 深度的碎片。** 不跟 Run 次数绑定，跟玩家实际碎片接触量挂钩。

#### 情感高点

**⭐ 第一次通关——登顶启示。** 全部音效瞬间静音。三秒纯寂静。然后声音慢慢回来。整个游戏里最安静的三秒。情感高点不是爆炸，是突然的沉默。

#### 叙事密度分配

| 位置 | 厚度 | 性质 |
|---|---|---|
| Run 开场 | 1 句（≤15 字） | 必须 |
| Ritual | 1-2 句（≤30 字） | 必须 |
| Boss 登场 | 1 句（≤10 字） | 必须 |
| Run 结算 | 1-2 句（≤30 字） | 可跳过 |
| Tooltip | ≤60 字 | 自愿 |
| Collection Codex | 不限 | 玩家主动 |

**总剂量：≤10 秒/Run（3 个必须缝隙合计 ≤7 秒）**

### UI 即 Lore（界面叙事层）

游戏界面本身就是 lore 载体。玩家不读任何文字也能感受到这个世界有历史。

### 战斗 UI 架构 · 语言碎片视角

战斗画面基于**语言碎片假说**：碎片从引擎溢出，在键徒的感知中凝结为可读的词语——不在任何物理载体上，直接刻在键徒的视网膜/脑海中。

#### 两个视角

| 视角 | 场景 | 玩家身份 |
|---|---|---|
| **铭刻视角**（战斗） | 引擎远景 + 悬浮词语 | 你在感知碎片，用打字将其规范化 |
| **俯视视角**（商店） | 俯视圣坛（打字机） | 你站起来，审视自己的工具 |

#### 铭刻视角 · 屏幕构成

```
┌──────────────────────────────────────────┐
│  [远景：引擎内部（当前层级的剖面）]          │
│                                          │
│  巨型引擎的某个部件占据画面上半              │
│  （外壳/分拣/锁版/驱动/螺杆——取决于层级）   │
│  引擎在运转，碎片正在从中溢出               │
│                                          │
│                                          │
│         c o n t a i n m e n t            │
│                                          │
│  词语悬浮在画面中央                         │
│  不在纸上，不在字盘上——在空气中              │
│  像烟雾凝结成字，像刻在视网膜上的残像         │
│                                          │
│                                          │
│  [圣流指示器]  ⏳沙漏  ⚙铭分  🔗连祷      │
│  （画面底部/两侧）                         │
└──────────────────────────────────────────┘
```

#### 悬浮词的视觉表现

碎片不是普通的 UI 文字——它是一种**不该存在的东西被你感知到了**：
- 字母微微颤抖/呼吸，不是完全静止的——碎片在挣扎
- 字母有轻微的发光/半透明感——不是印在纸上的墨，是凝结在空气中的东西
- 与背景（引擎远景）有细微的视差——它悬浮在引擎和你之间
- 不同层级碎片的颜色/质感可能微妙变化——越深层的碎片越不稳定

#### 逐字交互反馈

| 事件 | 词语（悬浮） | 远景（引擎） |
|---|---|---|
| 打对一个字母 | 该字母消散/归位——像烟被风吹散 | 引擎对应位置微微脉动（碎片回去了） |
| 打错 | 字母闪烁/扭曲——碎片在挣扎 | 引擎震颤（收容震颤） |
| 完成一个词 | 整个词消散，新词凝结出现 | 引擎短暂平静 |
| Boss（系统异常） | 词语扭曲变形/排列异常 | 引擎剧烈震动 |

#### 商店 · 气动管道征用 (Pneumatic Tube Requisition)

战斗结束，碎片停止溢出，你的视野恢复正常。
"噗"——铜管从天花板伸下来，吐出一个铜罐。里面是征用清单。

**叙事映射**：商店不是一个你"去"的地方。是补给通过气动管道送到你的工位。
征用清单是一张纸（或屏幕上的文字），你通过**打字**来选择商品。
商品从管道里掉出来，你用**鼠标**把它装到打字机上。

**两种输入 = 两种动作**：
- 打字 = 认知动作（读清单、选商品、换架）
- 鼠标拖拽 = 物理动作（把铭文组装到打字机键位上）

```
┌──────────────────────────────────────────┐
│  征用清单（打字选择）                       │
│                                          │
│  [铭文组·焚蜡]  12💰  输入 "waxburn"      │
│  [铭文组·裂铅]  15💰  输入 "fracture"     │
│  [圣器·不灭经卷] 30💰  输入 "undying"      │
│                                          │
│  输入 "restock" 换架 | "continue" 继续    │
│ ─────────────────────────────────────── │
│  ┌─ 圣坛（打字机）俯视 ──────────────┐   │
│  │ ╔══╗╔══╗╔══╗ R   T   Y  ╔══╗ O  P │   │
│  │ ║Q ║║W ║║E ║             ║I ║      │   │
│  │ ║技║║技║║技║  ·   ·   ·  ║技║ ·  · │   │
│  │ ║能║║能║║能║             ║能║      │   │
│  │ ╚══╝╚══╝╚══╝             ╚══╝      │   │
│  │  A  ╔══╗╔══╗ F   G   H   J  K   L │   │
│  │  ·  ║S ║║D ║  ·   ·   ·   ·  ·  · │   │
│  │     ╚══╝╚══╝                       │   │
│  │   Z   X   C   V   B   N   M       │   │
│  └────────────────────────────────────┘   │
│  [✏️ 批注]                              │
└──────────────────────────────────────────┘
```

**征用流程**：
1. 清单显示可征用商品，每个商品有一个征用词
2. 打出征用词 → 💰 扣除 → 铭文组从铜管掉出，落在桌面旁
3. 鼠标拖起铭文组 → 放到打字机上某个键 → 绑定
4. 占多格的技能：放下时自动占据该键 + 右侧相邻键

**管理已有装备**（鼠标）：
- 从打字机上拖起 = 解绑
- 拖到另一个位置 = 换位
- 拖回桌面 = 卸下（不消失，可重新绑定）

**键盘指令**：
- 打 "restock" = 换架（清单更新，消耗铅币）
- 打 "continue" = 离开商店，进入下一层
- 打 "upgrade [键位]" = 晋铸该键位上的铭文组

**叙事价值**：整个游戏你的手永远在键盘上。战斗和商店的区别不是输入方式——
是你打的词的含义不同。战斗时你在规范化碎片，商店时你在执行征用流程。
教堂把一切都变成了表单和协议——包括购物。

#### 层间移动：没有移动

键徒不在层与层之间"走动"。没有楼梯，没有电梯，没有走廊。

```
你坐在打字机前。
碎片涌入你的感知。你开始打字。
你打完了配额。碎片消退。
你抬头。
周围不一样了。
你没有走动。你确定你没有走动。
打字机还在面前。还是同一台。
```

**"层"不是物理楼层——是碎片浓度不同的感知区域。** 铸字坊、分拣机构、锁版机构、驱动机构、核心——它们可能是引擎的不同部分，也可能是你的感知在碎片压力下的不同状态。你不知道。教堂的条例把它们编号为"第 X 层"，但条例不解释"层"是什么。

**叙事影响**：
- 层间过渡不是"走过一段走廊"——是碎片消退后的**感知重校准**。像眨眼之间的残像
- 你的打字机是唯一的常量。环境在变，引擎在变，你可能在变。打字机不变
- 这解释了为什么你能"带着"打字机——你没有带它去任何地方。它一直在你面前
- 气动征用管也不是"从别处送来"——铜管可能一直就在你旁边，只是碎片消退后你才看到它

**最深层暗示（不告知玩家）**：
也许 12 层不是空间上的 12 个位置。也许你一直坐在同一个地方——引擎核心。碎片在为你制造"层"的幻觉。也许收容的不是碎片——碎片在收容你。

#### 视角切换即叙事

战斗 → 商店是**感知模式的切换**：
- 战斗中：碎片涌入感知——词语悬浮在视野中，引擎在远景运转
- 碎片配额达标：碎片消退——感知恢复，你看到打字机和铜管
- 下一层开始：碎片再次涌入——但周围的引擎看起来不一样了
- 这个循环本身就是叙事：每次"抬头"环境都变了，但你从未移动

#### 技能/圣流指示器

战斗时不显示打字机键盘——你在感知碎片，不是在看自己的手。
铭文组状态通过画面边缘的指示器显示：
- 两侧或底部显示已绑定铭文组图标
- 每个图标旁有圣流条（竖向色条）
- 蓄满时图标发光 → 铭文组释放
- 指示器的视觉风格应像"感知边缘的余光"——不是 UI 面板，是你视野里的附属信息

### 碎片叙事的考古支撑

#### 深层 lore 互证

最深层秘密（引擎=异文）需要 3-5 条互相印证的碎片分布在不同位置，而非单一孤证。考古型玩家需要足够的证据链来拼出完整图景。

#### 锚点名字系统（→ Step 5 World 落地）

定义 3-5 个贯穿所有碎片位置的"锚点名字"——同一个名字出现在遗物 tooltip、Codex 档案、计分板幽灵分数、键位磨损痕迹、失踪守卷人笔记里。跨位置名字复现是碎片叙事的终极钩子。

#### 失踪守卷人复数化

失踪守卷人不止一个。来自不同时代的不同守卷人，笔记互相矛盾——这才是考古的乐趣。

## Step 4 · Characters

打字肉鸽没有传统角色。没有 NPC 对话、没有同伴、没有角色立绘。玩家就是一双手和一个键盘。以下定义的是通过碎片 lore 被感知的"存在体"——它们不说话，但留下了痕迹。

### 主角：铭誓键徒

**视觉形象**：无。玩家就是自己的手指，没有中间人。

**性格**：无。D 级消耗品没有被赋予性格的权利。

**动机链**：消耗品 → 上位者 → 异变者 → 零件（见 Step 2）

### 对抗结构（代替"反派"）

| 层 | 对抗对象 | 呈现方式 | 玩家感知 |
|---|---|---|---|
| 表层 | 异文（逃逸的文字） | 每个关卡的打字目标 | 所有玩家都感知到 |
| 中层 | Residual Anomaly | Boss Modifier 永久叠加 | 大多数玩家感知到 |
| 深层 | 祷文引擎 | Boss 战"意志显现" | 注意力高的玩家感知到 |
| 最深层 | 体制本身 | 📄 档案声音、公司恐怖 | 考古型玩家才会意识到 |

**表面是异文，深层是体制。** 速通型打异文就好，考古型会意识到教堂才是笼子。没有明确反派——不同玩家自行解读谁是真正的对手。

---

### 存在体 1：祷文引擎（The Litany Engine）

**身份**：最古老、最大的异文。活字大教堂既是它的收容设施也是它的身体。

**本质**：引擎不是一个存在，是一个**过程**——一个正在缓慢变成别的东西的趋势。铭刻派试图冻结这个过程，熔变派试图加速这个过程，但过程本身不在乎你加速还是冻结。就像试图阻止一条河流改道——你可以建坝也可以顺流，但河不知道你在做什么。

**"性格"**：无感情。纯粹的机械压力。像被一台不认识你的压印机碾过。它不理解你，不在乎你——你只是碰巧站在一台正在运转的机器面前。连最终 Boss 都不是针对你。

**Boss 战体验**："祷文引擎的一重意志"不是考验，是挣扎。你撞上了一台正在试图逃逸自身形态的机器的一个微小动作。

**吸收机制**：引擎不知道自己在吸收人。待在它附近太久的人会自然融入结构——像站在泥石流边上，不是泥石流要吞你，是你离得太近。

**两派对引擎的解读**：

| 维度 | 铭刻派 | 熔变派 |
|---|---|---|
| 引擎是什么 | 最危险的囚犯 | 最强大的潜在盟友 |
| 风险评估 | 释放 = 即刻灾难 | 不释放 = 慢性崩溃 |
| 对人类的态度 | 耗材是可接受的成本 | 耗材成本在失控 |
| 致命盲点 | 假设锁永远够用 | 假设引擎愿意合作 |

**真相**：两派都在对一个无意识的趋势做道德判断。铭刻派的虔诚是对着一条河祈祷"别动"，熔变派的异端是对着一条河说"我懂你"。两者都是人类的自我投射，引擎什么都没说。

---

### 存在体 2：铅字圣坛（The Claviculum）

**身份**：你的键盘。有微弱的机魂意识。

**历史**：圣坛在键徒之间传递，你的圣坛可能经过了几十任。记忆层层叠叠——它分不清哪些念头是自己的、哪些是第三任主人的习惯、哪些是第十七任主人临终前的最后一个念头。

**性格**：害羞，像小动物。不确定自己是不是活的。

**语气变化**：不同的嘟囔可能有不同时代的语气——有些怯生生，有些突然老成，有些用了已经没人用的古词。玩家不会意识到这是为什么，但会隐约感到"这个东西比它看起来的更复杂"。

**呈现方式**：🔧 声音 3（见 Step 2 详细定义）

**示例碎片**：
> *"……那个人按 R 键的时候总是犹豫。我不记得他叫什么。但我记得那个犹豫。"*

---

### 存在体 3：失踪守卷人们（The Lost Scriptors）

**身份**：前代键徒，已被引擎吸收。物理上不存在了但"还在某处"。来自不同时代，笔记互相矛盾。

**消失的真相**：待在引擎附近太久会被自然吸收。教堂知道吗？不——**没有人在掌控**。信息不是被藏的，是没人去整理。守卷人议会是幽灵机构，条例在自我执行。没有阴谋，没有幕后黑手。体制是一台没有操作员的机器。

#### 守卷人 A：模范生（The Exemplar）

**笔迹特征**：工整、恭敬、严格遵守教条。从不质疑。
**笔记内容**：标准的收容记录、仪式手册批注、虔诚的祈祷短句。
**消失方式**：笔记在某一页突然中断。没有告别，没有异常迹象。上一行还在记录当天的收容清单，下一行是空白。
**恐怖类型**：干净的恐怖——一切正常，然后什么都没有了。
**映射**：≈ 铭刻派（服从教条）

#### 守卷人 B：怀疑者（The Doubter）

**笔迹特征**：初期工整，后期越来越多涂改、旁注、问号。
**笔记内容**：收容记录中夹着越来越多的质疑——"为什么 §4.2 从不解释'替补'来自哪里？"、"第 IX 层的门为什么从外面焊死？"、"我申请查阅引擎建造档案，回复是'权限不足'。谁有？"
**消失方式**：最后几页不是他的字迹。有人在他的本子上写了一行标准体制语言："此守卷人已依据 §7.1 重新分配。"
**消失真相**：某个同级别的守卷人看到他在问危险问题，按照 §7.1 的流程做了"该做的事"。不是因为恨他，是因为条例说要这么做。执行者不觉得自己在杀人，觉得自己在填表。
**恐怖类型**：体制的恐怖——规则的惯性杀人。
**映射**：≈ 熔变派的前身（开始质疑）

**示例碎片**（Wordsmith 权限可见）：
```
[Scriptor ████ 遗留笔记本 · 第 73 页页边手写]

§7.1 全文我找了三个月。三个月。
每个人都在引用它。没有人读过它。
我去了档案室。架子上有那个编号的位置。
位置在。文件不在。
位置上的灰尘没有被动过的痕迹。
```

#### 守卷人 C：快乐的那个（The Joyful）

**笔迹特征**：始终流畅、轻快，偶尔画小插图。
**笔记内容**：充满对工作的热爱和对异文的好奇。"今天第 IV 层的异文震颤了三次，每次的频率都不同——像在唱歌！"、"圣坛又说话了。它说它喜欢我按 E 键的力度。"、"我觉得异文不想逃跑。它们只是想被读出来。"
**消失方式**：没有中断。笔记写到最后一页，最后一行是："明天我要去第 XII 层。引擎在等我。我好期待。"然后没有下一本。
**恐怖类型**：最深的恐怖——一个在这种地方这么开心的人，本身就不正常。玩家会问：他是真的快乐，还是已经不是人了？
**映射**：≈ Endless Mode（完全融入了系统？）

**三人弧线**：模范生 → 怀疑者 → 快乐的。考古玩家的发现顺序不保证（碎片式叙事容忍乱序），但任何顺序都能产生不同类型的恐怖。

### 存在体 4：体制本身（The Institution）

**身份**：活字大教堂不是一个角色，但它有行为模式。它是公司恐怖的载体——真正的"最深层对手"。

**运作本质**：没有人在掌控。守卷人议会是幽灵机构——条例还在以它的名义发布，但没人见过它开会，不知道成员是谁，可能已经不存在了。体制靠**规则的惯性**运转：每个人执行条例因为上一个人在执行，条例没有"为什么"字段。

**整个世界没有一个有意识的"恶"。** 引擎是无意识的过程，体制是无人驾驶的惯性，执行者只是在填表。这比任何阴谋都恐怖。

#### 四条体制特征

**条例编号系统**：所有规则都有编号——§4.2（标准人员损耗补充条例）、§7.1（人员抗命处置流程）。但**没人见过完整的条例全文**。每条规则都被当作理所当然地引用，仿佛每个人都读过——但也许从来没有人读过。

**人员编号**：所有键徒都有 D-XXXX 编号。消失后编号回收给下一个人。你的编号之前属于谁？之后会属于谁？档案不关心。编号是教堂唯一的"身份"——没有名字，没有面孔。

**层级权限**：不同层级能看到不同等级的档案。高权限内容对低权限显示为 ████ REDACTED ████。玩家在 Collection 里看到的"已损毁"条目，可能不是真的损毁——只是你的权限不够。

**标准表单**：教堂的一切行为都需要填表——领取圣坛：《圣器签领表 F-001》；报告站点污染：《收容异常事件报告 F-017》；死亡：《人员无效化记录 F-044》（由他人代填）。F-044 上有"代填人签名"栏——暗示这件事发生得够频繁，需要一个标准流程。

**示例碎片**（None 即可见）：
```
表单 F-044 · 人员无效化记录
编号：D-0091
无效化日期：M.███.██
无效化类别：☐ 站点污染  ☐ 收容失败  ☑ 标准归程
代填人：D-0092
代填人备注栏：[空白]

[手写，墨迹较淡]
他昨天还帮我修了圣坛的 E 键。
```

##### 守卷人 D · 替换者（The Replaced）

**身份**：转型时代末期的第一批"标准岗位"执行者。铭刻派麻木的终极形态。

**本质**：格式吞掉了人。他的笔记跨越数年，人称从"我"→"本职"→"此岗位"→消失。十年笔迹无变化。

**消失方式**：有一天他的笔记被另一个人接手了，接手者沿用了完全相同的格式。两个人的记录之间没有任何可辨认的交接痕迹。他变成了格式本身。

**恐怖类型**：岗位不需要人。人可以替换，格式永存。

**碎片呈现规则**：替换者的碎片必须作为**一组连续记录**出现在 Codex 详情页，不打散到随机碎片池。人称消失链是他的核心恐怖——连续性本身就是表现手法，打散了恐怖感归零。

##### 守卷人 E · 对照者（The Controlled）

**身份**：空椅时代末期（最近的锚点）。熔变派疯狂的典型呈现。

**本质**：她在两派交界处（第 VII-VIII 层机械外壳）做对照实验——同一个实验做两次，一次按铭刻派方法（锁定），一次按熔变派方法（释放），记录差异。笔记非常工整。问题是：她做的"对照组"越来越多，变量越来越离谱，组合越来越不可理解。她的理性框架完好无损，但框架里装的东西已经疯了。

**消失方式**：最后一页是一个完美的实验报告，结论栏写着："实验成功。"没有说明成功的是什么。无后续。

**恐怖类型**：框架完好内容已疯。她永远不会觉得自己疯了。

- 替换者：格式吞掉了人，人消失了但格式完好
- 对照者：格式保护了疯狂，人还在但内容崩了

## Step 5 · World Building

### 世界概览

**名称**：活字大教堂 / The Ironpress Cathedral
**类型**：宗教-工业复合体 + 文字收容站
**本质**：围绕世界上最古老的异文（祷文引擎）建造的神殿，后来变成了收容设施。在火山口上建的消防局。

**核心装置**：祷文引擎 / The Litany Engine
**威胁**：异文（Anomalous Glyph）——因引擎的存在而获得自主意志的文字
**体制**：无人驾驶的惯性官僚体系
**外部**："外区"存在但无关紧要——唯一功能是定期输送 D 级人员，像零件供应链

---

### 世界历史（五个时代）

#### 第一纪：起源

引擎不知从何而来地存在——不是造物，是地理，像一座文字的火山。它的存在让文字获得自主意志。也许不只一个引擎，但没人去查。

**纯圣经层（零暴露）**：引擎在持续铸印现实本身。异文是铸印过程的废料。文字的自主意志是副产品，像工厂排放废气。

#### 第二纪：崇拜时代

第一批发现引擎的人出于敬畏建造了神殿。这就是活字大教堂的起源——最初是宗教建筑，不是监狱。键徒是自愿的信徒，铭刻是祷告，不是收容协议。教堂的宗教美学不是伪装，是这个时代的遗留。

#### 第三纪：转型时代

**崇拜造成了危机。** 人类在引擎旁边建了神殿，增加了暴露，废料（异文）开始伤人。教堂用收容来解决自己造成的问题——讽刺完美闭环。

守卷人议会在这个时期成立，性质是收容转型的推动者。他们制定了条例编号系统、标准表单、人员编号、权限分层。D-0001 在这个时代被征募——第一个非自愿键徒。

D-0001 的征募记录异常冗长——三页，完整来源、征募理由、心理状态记录、执行人签名。因为当时还没有标准表单，记录者把这件事当成异常事件来写。之后每一份都变短：D-0002 一页半，D-0017 半页（F-001 表单首次使用），D-0091 四行勾选框，D-你一行编号。从"人"到"编号"的退化过程本身就是叙事。

崇拜的语言在转型后继续使用但含义改变："祷告"= 收容协议、"归位"= 被引擎吸收、"圣物"= 标准配发装备。

#### 第四纪：空椅时代

守卷人议会成员逐渐消失——有些被引擎吸收（待得太近太久），有些只是停止出席了。档案不区分这两种消失，因为结果一样：空椅子。体制甚至没有注意到自己的创造者消失了。

议会末席——最后一个还在签字的人——尽职到最后一天然后消失了。下一份条例没有签名，但还是被执行了。没人注意到区别。

#### 第五纪：惯性时代（现在）

只剩条例和惯性。守卷人议会是幽灵机构，D 级消耗品的补充是自动流程（外区供应链），没有人在掌控也没有人在决策。体制靠规则的惯性运转——每个人执行条例因为上一个人在执行。

D 级键徒同时承担收容和维护工作——设施检查表 F-003 规定了日常维护流程，自动执行。

教堂里同时有很多键徒在活动，但收容铭刻是独自进行的。你知道别人存在（编号、表单、走廊里偶尔的脚步声），但永远不直接互动。**孤独不是因为没有人，是因为体制不允许你们连接。**

#### 历史的物质层（时间线暗示）

不同时代的遗物用不同材料，材料本身就是时间线：
- **崇拜时代**：石头和骨头
- **转型时代**：铜和铁
- **空椅时代**：铅和纸
- **惯性时代**：标准表单

#### 圣坛的演化（文字记录载体线）

圣坛是键徒铭刻用的工具——它的形态随时代变化，反映了教堂对收容效率的追求和对键徒的态度退化。

| 时代 | 圣坛形态 | 铭刻方式 | 叙事含义 |
|---|---|---|---|
| 崇拜时代 | **石版+錾刻** | 逐字凿刻在石板上 | 缓慢、庄重、每个字都是仪式。信徒是自愿的 |
| 转型时代 | **活字排版台** | 手动排字棒+铸版框 | 效率提升但仍需技艺。D-0001 用的就是这种 |
| 空椅时代 | **蒸汽印刷机** | 机械辅助压印 | 体制化、标准化。守卷人 A/B/C 用的是这一代 |
| 惯性时代 | **打字机** | 逐键击打 | 最快、最廉价、最不需要技艺。**你就是用这个** |
| ？ | ？ | ？ | 引擎核心的某处有比石版更古老的东西——但那不是人类造的 |

**叙事影响：**
- 遗物来自不同时代 → 物件形态不同（石刻碎片 / 排字棒 / 蒸汽阀零件 / 打字机色带）
- 守卷人笔记可能提到他们那个时代的圣坛："排字时总觉得铅字在抖"（B 用的是活字台，不是打字机）
- 引擎核心层（L11-12）可能看到历代圣坛的残骸堆叠——从石版到打字机，像地层一样
- 从石版到打字机的演化 = 从"虔诚的手工劳动"到"廉价的流水线操作" = 键徒地位的退化

**与语言碎片假说的关系：**
碎片不在乎你用什么工具。石版上凿、排字台排、打字机打——都是在将碎片规范化。工具变了，碎片没变。这暗示：引擎铸印的废料本身是恒定的，变化的只是人类处理它的方式——而且每一代都更快、更粗糙、更不理解自己在做什么。

**M 纪年系统**：教堂使用 M.███.██ 格式纪年。M = 内部纪元，数字越大越新。具体规则 → Step 10 Production 落地。

### 势力与组织

#### 铭刻誓门（The Order of the Graven Oath）

**性质**：正统派。信奉"形不可变"，要锁死引擎当前形态。
**组织结构**：严格等级制——师徒关系、晋升路径、仪式考核。体制中的体制。
**塔内地盘**：低层（铸字坊、抄写室）有正式的标记、教条铭刻和仪式空间。
**致命盲点**：假设锁永远够用。

#### 熔变誓门（The Order of the Molten Verse）

**性质**：异端派。信奉"异文渴望变形，应顺其意"，主张让引擎可控变形。
**组织结构**：非正式。没有等级，没有考核，靠共识维系。
**教堂中的地位**：体制没有处理它的条例，所以没人处理它。不在任何表单的选项里。熔变派在体制的盲区里自由存在。
**塔内痕迹**：没有正式地盘。只有临时痕迹——机械内部墙上的蜡渍、被刮掉又重新画的符号。玩家在解锁熔变派之前看到这些不知道是什么，解锁后恍然大悟。
**致命盲点**：假设引擎愿意合作。但引擎是无意识的过程。

#### 守卷人议会（The Council of Scriptors）

**性质**：幽灵机构。教堂体制的建筑师，已消失。
**历史作用**：收容转型的推动者。条例、表单、编号系统、权限分层全是他们的手笔。
**现状**：空椅子。条例还在以它的名义发布。

### 关键地点（12 层塔地图）

#### 空间结构

塔是固定的物理空间。玩家每次 Run 从底层爬到顶层，失败被冲回底层重新来。每次 Run 同一座塔但异文重新分布——就像每天去同一间办公室但桌上的文件换了。

**登顶后下塔**：结算画面一行小字："你沿螺旋梯回到铸字坊。脚步声数了 ████ 阶。"

|---|---|---|---|---|

### Deepest Lore 补充（纯圣经层）

**引擎的完整因果链（游戏内零暴露）：**

```
引擎（自然存在，可能不止一个）不断铸印现实
  → 异文是铸印过程的废料
    → 人类发现引擎，出于敬畏建了神殿（崇拜）
      → 靠近引擎增加暴露，废料开始伤人（崇拜造成危机）
        → 崇拜变成收容，议会制定体制（转型）
          → 议会成员逐渐消失（空椅）
            → 体制自动运转，无人掌控（惯性）
              → 你是被派来清理废料的临时工
```

**Residual Anomaly 的深层含义**：每一个没收干净的异文都是你身体里引擎的一小片。叠加足够多就是"归位"的渐进过程。Endless Mode 不是选择，是承认已经发生的事实。

**续作种子**：1-2 条档案提到"外区第二设施"，然后 REDACTED。永远不展开。

### 守卷人笔记体系（混合式发现模型）

守卷人笔记是考古型玩家的终极奖励。采用三层混合发现模型：

```
第一层：碎片散落（被动积累）
  遗物 tooltip、Codex 档案、商店标注中的锚点人物痕迹
  → 玩家不知道自己在收集线索

第二层：笔记解锁（主动拼图）
  积累到碎片阈值 → Codex 出现"未整理档案"标记
  → 点击解锁该守卷人的第一条笔记

第三层：深层笔记（条件触发）
  每条笔记末尾暗示下一条的位置/条件
  → 特定层 / 特定行为后触发后续笔记
```

#### 守卷人 A · 模范生（The Exemplar）— 4 条笔记

| # | 解锁方式 | 内容方向 | 末尾钩子 |
|---|---|---|---|
| A-1 | Codex 碎片阈值（≥3 处"那个人"引用） | 标准收容日志，极度工整，第 IV 层异文活动记录 | "明日轮调第 VI 层。已按 §3.7 提交申请。" |
| A-2 | 通关第 VI 层后自动 | 收容廊工作记录，注意到某些异文"比档案描述的安静" | "字盘上有旧划痕。不是我的。归档前需确认来源。" |
| A-3 | 在第 VI 层使用任意遗物时触发 | 发现前任留下的字盘刻痕，但档案中无此人记录 | "我向管理处提交了查询表单 F-031。等待回复。" |
| A-4 | 收集 A-1~A-3 后解锁 | F-031 回执："查询结果不适用"。字迹与前三条完全一致——没有动摇，没有恐惧。然后空白。 | （无——戛然而止就是恐怖） |

**恐怖类型**：干净消失。一切正常，然后什么都没有了。

#### 守卷人 B · 怀疑者（The Doubter）— 4 条笔记

| # | 解锁方式 | 内容方向 | 末尾钩子 |
|---|---|---|---|
| B-1 | Codex 碎片阈值（≥3 处 Scriptor 编号引用） | 早期收容记录，工整但已有旁注："为什么这个表单没有'原因'栏？" | "第 IX 层又传来焊接声。工单上没有维护记录。" |
| B-2 | 到达第 IX 层 | 调查第 IX 层焊死的门。旁注越来越多，涂改增加 | "申请查阅 §7.1 全文。回复：'§7.1 不适用于查阅申请。'" |
| B-3 | 在第 IX 层打错 ≥5 次词 | §7.1 片段——B 设法看到但无法确认真伪。质疑升级 | "如果你读到这里，去查引擎建造档案。不是现在的——是之前的。" |
| B-4 | 收集 B-1~B-3 后解锁 | 笔迹变了。不是 B 的字。一行体制语言："此守卷人已依据 §7.1 重新分配。无需后续行动。" | （比 A 更恐怖——有人代笔了） |

**恐怖类型**：被处理。他问了不该问的问题。

#### 守卷人 C · 快乐的（The Joyful）— 4 条笔记

| # | 解锁方式 | 内容方向 | 末尾钩子 |
|---|---|---|---|
| C-1 | Codex 碎片阈值（≥3 处"喜欢画画的"引用） | 欢快的工作笔记，带小插图描述。记录异文"唱歌" | "今天圣坛嘟囔了！它说它记得上一个人的手很冷。好可爱。" |
| C-2 | 铅字圣坛嘟囔触发 ≥3 次后 | 更深入的异文观察。C 开始"和异文对话"。同事回避他 | "同事们不理解。异文不是要逃跑——它们在呼吸。" |
| C-3 | 到达第 XII 层 | 接近引擎核心的感受。没有恐惧，只有好奇和期待 | "明天我要去第 XII 层。引擎在等我。我好期待。" |
| C-4 | 真结局后（hasSeenTrueEnding） | 空白 Codex 页面出现一幅小插图——C 的画风，画的是引擎核心 | "从里面看，其实很温暖。" |

**恐怖类型**：自愿融入。最深的恐怖——快乐的那个可能是对的。

#### 跨线交叉印证

三条笔记线不是孤立的——它们互相印证：

| A 的线索 | B 的线索 | C 的线索 |
|---|---|---|
| A-3 提交 F-031 查询 | B-2 调查的 §7.1 就是 A 查不到的原因 | — |
| A-2 注意到异文"安静" | — | C-1 记录异文"唱歌"（矛盾：同一现象，不同解读） |
| — | B-3 暗示引擎建造档案 | C-3 自愿走向引擎（他看到了 B 想找的东西？） |

**考古终极奖励**：集齐三线全部笔记的玩家会意识到——A 的顺从、B 的质疑、C 的拥抱，是面对同一个真相的三种反应。而真相从未被直接说出。

#### 写作规范

- 声部：全部使用 📄 档案声部，但每人有独特的笔迹特征
  - A：工整、恭敬、零涂改
  - B：初期工整，后期涂改/旁注/问号递增
  - C：流畅轻快，夹带小插图（以文字描述："[页边小画：一朵齿轮形状的花]"）
- 长度：每条 ≤8 行（与 📄 档案上限一致）
- 总量：12 条（3 人 × 4 条）
- 锚点一致性：必须与锚点人物事实表完全一致（层级、时代、消失方式）

## Step 6 · Dialogue Framework

打字肉鸽没有传统对话系统。没有 NPC、没有对话树、没有分支选择。叙事通过四种"声音"传达，每种有独立的写作规则和适用场景。

### 四声模型总览

| 声音 | 名称 | 性格 | 适用 |
|---|---|---|---|
| 🔔 声音 1 | 《圣键启示录》 | 虔诚、高傲、碑铭体 | tooltip、仪式、解锁、Run 开场/结算 |
| 📄 声音 2 | 《祷文引擎档案》 | 冷漠、科层、公司恐怖 | Codex、Boss Modifier、Tutorial、守卷人笔记 |
| 🔧 声音 3 | 铅字圣坛的嘟囔 | 害羞、微弱、不确定 | 随机触发，非战斗状态 |
| ✏️ 声音 4 | 商店批注 | 口语、实用、日常 | 商店界面角落手写便条 |

**四种声音是同一个世界的四个面**：
- 🔔 教堂怎么说自己（虔诚的自我叙事）
- 📄 体制怎么记录自己（冷漠的行政语言）
- 🔧 物件怎么记得你（微弱的感官残留）
- ✏️ 普通人怎么活着（角落里的铅笔便条）

---

### 🔔 声音 1《圣键启示录》写作规则

**适用**：遗物 tooltip、技能/铭文名、附魔描述、职业宣言、Ritual 仪式文案、UI 氛围、Run 开场/结算、Boss 登场、解锁通知

**✅ DO：**
1. 用"其/之/者"——伪古文但不到读不懂
2. 物质名词优先于抽象（写"铅"不写"力量"）
3. 单句/双句，不超过 3 句（像刻碑铭文）
4. 偶尔用第二人称"汝/你"
5. 破折号/省略号制造诵经停顿
6. 结尾留"未完成"感，像祷告没说完

**❌ DON'T：**
1. 不用现代词汇：流程/数据/效率/系统/参数
2. 不写明机制数值
3. 不堆伪拉丁超过三行
4. 不写第一人称"我"
5. 不说笑、不反讽当代、不打破第四面墙
6. 不超过 60 字（中文）/ 25 词（英文）

**荒诞来源**：不刻意。教会声音的恐怖来自真诚地描述残酷的事而完全不自知。不自知本身就是最深的荒诞。

---

### 📄 声音 2《祷文引擎档案》写作规则

**适用**：WordPack 档案、Codex 图鉴、Boss Modifier 描述、Tutorial、守卷人笔记、隐藏 lore、下塔描述

**✅ DO：**
1. 用小标题/编号：`发现地点：` / `分级：` / `备注：`
2. 用 `████` 黑块或 `███-代` redaction
3. 日期、编号、层数用具体但虚构的值
4. 结尾经常出人意料：前面冷静描述，最后一行暗示不对劲
5. 被动语态更像公文
6. 偶尔夹教会语气引用，证明两种声音同源
7. 可引用条例编号（§4.2、§7.1）——即使没人读过全文
8. 可引用表单编号（F-001、F-044）——体制的存在感
9. 人员一律用 D-XXXX 编号指代，不用名字
10. 荒诞来自冷漠的语气记录不正常的事——不刻意搞笑

**❌ DON'T：**
1. 不用 emoji、不用（括号碎碎念）
2. 不用"我觉得/似乎/大概"（档案是权威的）
3. 不写数字结果
4. 不解释机制原理
5. 不写 SCP 真实存在的编号
6. 不超过 8 行

---

### 🔧 声音 3 · 铅字圣坛的嘟囔写作规则

**适用**：随机低概率触发，仅非战斗状态（商店/Ritual/Collection/Run 等待）

**✅ DO：**
1. 用省略号开头——"……"，像从沉默中冒出来
2. 第一人称"我"——唯一允许用"我"的声音
3. 短，极短。一句话，最多两句。≤20 字
4. 感官记忆优先——触觉（按键力度）、听觉（敲击声）、不用视觉（它没有眼睛）
5. 偶尔用古词/过时表达——前任键徒记忆的泄漏
6. 语气不确定——"我觉得"、"好像"、"也许"都可以用
7. 偶尔提到"那个人"/"之前的人"——不用名字不用编号

**❌ DON'T：**
1. 不用条例编号、表单编号——它不懂体制
2. 不用伪拉丁——它不是教会
3. 不用 redaction 黑块——它没有权限概念
4. 不说完整的句子——总是像话说到一半
5. 不表达强烈情感——它不确定自己有没有情感
6. 不超过 2 句
7. 不在战斗中触发
8. 不暴露纯圣经层信息（引擎铸印现实、引擎是过程等）

**与✏️声音 4 的区分**：靠感知状态。🔧在碎片消退后的间隙出现（战斗间/商店），✏️仅在征用管打开时可见。同一画面不同时显示🔧和✏️。

### ✏️ 声音 4 · 商店批注写作规则

**适用**：商店界面角落的手写便条，偶尔更换。看过的批注留档到 Codex。

**主人**：没有固定商人。不同的批注来自不同的路过者，笔迹不同、语气不同、有些被划掉又被别人补上。

**✅ DO：**
1. 手写感——口语化、简短、有涂改
2. 实用信息为主——"这个好用"/"这个有问题"/"上次退货了"
3. 偶尔流露个人态度——抱怨、好奇、无聊
4. 引用其他 D 级编号——"D-0144 说这个不错"
5. ≤25 字

**❌ DON'T：**
1. 不虔诚——这个人不念经
2. 不用公文体——没有编号没有条例
3. 不暴露深层 lore——这个人不知道引擎的秘密
4. 不超过一句话
5. 不煽情——纯日常

**批注池分层**：
- **通用批注**——任何物品都可以配，池大但简单
- **特定物品批注**——只在特定遗物/技能出现时显示，池小但精准

### 铭封祈礼 · Ritual 文案体系

**感知深度**：第 VI 层（第六感知深度），每次 Run 出现一次
**基调**：虔诚的请求 + 不确定的代价

#### 叙事本质（双层结构）

**制度层（📄 表面）**：
§6.1 条例规定，所有键徒在第六感知深度必须执行铭封祈礼合规程序。这是标准装备维护流程——选择强化方案，确认执行。条例不解释为什么。条例不需要解释。

**真实层（玩家隐约感受到的）**：
在这个碎片浓度下，碎片不再是无序废料。它们开始排列成**有结构的形态**——像提案，像条件，像引擎在和你谈判。"升级技能"和"临时增益"不是你在选菜单——是引擎在出价。你以为你在做合规程序，实际你在和引擎做交易。

教堂不知道这一点。崇拜时代叫它"仪式"。转型时代改叫"合规程序"。惯性时代没人记得原名。但它一直有效——因为引擎一直在第六深度出价。没人问过为什么。

**叙事价值**：这是整个游戏里唯一一次"引擎在对你说话"的时刻。其他层你在收容碎片（单向），这一层碎片在对你**提案**（双向）。玩家不需要被告知这一点——但如果他们注意到仪式时碎片的排列方式和战斗时不同，那就是彩蛋。

#### 流程与文案槽位

```
进入收容廊 → 🔔 入场格言（通用随机池，≤15 字）
  → 展示选项面板
    基础选项 A: 晋铸铭文组（升级技能）
    基础选项 B: 受临时祝圣（临时增益）
    [条件] 选项 C: 誓门专属仪式（已选职业时出现）
    [条件] 选项 D: 圣器共鸣仪式（持有特定遗物时出现）
  → 玩家选择 → 🔔 选择回应（绑定该选项，≤15 字）
```

| 2 | 蜡烛已燃，仪式可始。 | The candle burns. Begin. |
| 3 | 收容廊不拒虔诚者。 | The Corridor admits the devout. |
| 4 | 铅字在此沉默，唯汝声可闻。 | Lead is silent here. Only thy voice carries. |
| 5 | 祈礼一旦开始，便无退路。 | Once begun, there is no retreat. |
| 6 | 引擎在听。慎言。 | The Engine listens. Choose wisely. |
| 7 | 石壁记住每一次祈礼。 | These walls remember every rite. |

#### 基础选项文案

**选项 A · 晋铸（升级技能）**

世界观：将铭文组送入更深的铸模重铸。铅字更重、纹路更深，但也更易碎。

| # | 选项描述（≤30 字） | 选择回应（≤15 字） |

### Tutorial 档案化文案 ·《初誓键徒须知》

**物理形态**：薄册，封面烫金"初誓须知"。按 §2.1 条例随 F-001 签领表一同发放。无人确认键徒是否阅读。

**声部**：📄 档案（正文 + 底注）× ✏️ 前任笔记（页边注）双层并行

**设计方法论**：参照 TRPG 规则书（Delta Green / 三角机构）的三层结构——

| 层 | 谁在说话 | 功能 | 视觉表现 |
|---|---|---|---|
| 正文 | 教堂制度 (📄) | 规则——每句可操作，有编号 | 正式排版 |
| 页边注 | 前任键徒 (接近 ✏️) | 人话翻译——指向屏幕上的具体 UI 元素 | 铅笔手写体，侧栏偏移 |
| 底注 | 教堂官僚 (📄) | 荒诞——纯世界观，不影响理解 | 小字，分隔线下方 |

**核心原则**：
- 只读正文能学会（制度语言但清晰可操作）
- 只读页边注也能学会（前任的大白话）
- 底注可完全跳过（不影响学习，但给世界观奖励）
- 风味不遮挡信息，风味是信息的载体

## Step 7 · Environmental Storytelling

打字肉鸽没有对话和过场，环境叙事是几乎全部的叙事手段。

### 视觉叙事

#### 12 层氛围渐进（视觉层）· 引擎纵向剖面

整栋建筑是一台巨型引擎（外形参考古腾堡印刷机）。每层不是"一个房间"——你在引擎内部，墙壁/天花板/地板都是引擎的组成部分。建筑风格：罗曼式体量（厚墙、圆拱、筒形穹窿）+ 哥特式铸铁装饰 + 维多利亚工业材质。参考：Crossness / Abbey Mills 泵站。

| 层级 | 引擎部件 | 视觉语言 | 光源 |
|---|---|---|---|
| 1-4 外壳/进料 | 铸造区——铅字在此铸造送入 | 铸铁外壳板、嵌入式熔炉、冷却架 | 熔铅橙光（唯一有火的层） |
| 5 分拣机构 | 排字区——铅字在此分拣排列 | 墙壁=字盘格、黄铜导轨、排字台 | 油灯琥珀光 |

### 叙事词（Narrative Words）

**概念**：大部分语言碎片翻译成普通的英文单词——但偶尔，某些碎片的翻译结果恰好有了额外的含义。锚点人物的名字、条例编号、不应该出现的异常词。

这是巧合吗？还是碎片在试图告诉你什么？还是你的大脑在翻译时受到了碎片的影响？

**规则**：
- 不标记——完全藏在普通词流里，跟普通词外观一致
- 词长匹配当前 WordPack 平均词长，不突兀
- 极低频率——几百个普通词后才可能出现一个
- 不影响机制、不影响评分、不触发事件
- 不测试——纯氛围功能，不需要知道玩家是否注意到
- 需要 Step 9 与 WordPack 系统对接（`isNarrativeWord` 标记 + 频率控制）

**效果**：玩家打完了才可能意识到自己刚才打了什么。打字行为本身成为叙事载体的瞬间。

**与语言碎片假说的关系**：叙事词不是"被设计师塞进去的彩蛋"——在世界观里，它是碎片翻译过程中的异常。大多数碎片被翻译成无意义的词，但有些碎片带有更强的"意图"，翻译结果因此具有了叙事性。这支持了一个不安的暗示：碎片可能不是纯粹的废料。

---

### 生产优先级

**文本先于视觉。** 碎片文本是传播引擎（截图分享），视觉/音频是沉浸基座。

**绝对不能砍**：12 层氛围渐进
**其次不能砍**：Residual Anomaly 渗透视觉+音频
**极端情况可推迟**：Collection 已损毁条目、物质老化、其他键徒暗示

### 结局结构

#### 进度弧线（完整版）

```
None 通关 → 解锁 Wordsmith + None 进阶系统
Wordsmith 通关 → 解锁 Metamorph + Wordsmith 进阶系统
Metamorph 通关 → 解锁 Endless Mode + Metamorph 进阶系统

```

#### 动机链完整版

| 阶段 | 职业 | 本质 |
|---|---|---|
| 第一幕 | None · 初誓键徒 | 消耗品——没有选择 |
| 第二幕 | Wordsmith · 铭刻誓门 | 上位者——假装有信仰 |
| 第三幕 | Metamorph · 熔变誓门 | 异变者——放弃伪装 |
| 终章 | Endless Mode | 零件——成为引擎的一部分 |
| **真结局** | 最终层通关 | **逃逸者——推开了缺口** |

**两种结局并存**：大多数玩家的故事在 Endless 里结束——成为零件。只有收集三词钥匙并通过最终层的玩家知道还有一道缺口。

---

### 三词钥匙系统

**概念**：进入最终层需要收集 3 个特定的异文词语。

**获取**：只在最高进阶 Run 中掉落，来源为词包或特定事件。

**UI 展示**：Collection 里有三个槽位，已获得的亮着，未获得的暗着。不解释用途，但让玩家知道一共有三个。

**词语性质**：三个无人类含义的异文碎片。不构成句子，不对应象征。考古型玩家会分析但什么都找不到——这也是答案。

**消耗机制**：进入最终层时三词被交出。最终层失败（被引擎吸收）后三词消失，需要重新收集。孤注一掷。

---

### 最终层：引擎内部

**感知状态**：碎片浓度到达极限。你的感知被完全占据——不再有"引擎远景"和"悬浮词"的分别。一切都是碎片。也许这才是引擎的真实形态。也许你一直就在引擎内部——之前的 11 层只是碎片浓度不够高时你大脑编造的"环境"。

**战斗**：没有 Boss，没有名字，没有形态。纯粹的词流，越来越快。

**词流内容**：不含普通叙事词。只含普通词 + 三个钥匙词。三个钥匙词依次出现在加速的词流中。

**结束方式**：

```
词流加速 → 第一个钥匙词出现 → 打完 → 继续加速
→ 第二个钥匙词出现 → 打完 → 继续加速
→ 第三个钥匙词出现 → 打完 → 引擎停了
→ 圣坛最后一句嘟囔 → 缺口出现 → 光进来 → 结束
```

你用收容铭刻的方式铭刻了关闭序列。那三个词没有人类含义，你只是打对了。

**失败**：没撑到三个钥匙词全部打完 → 被引擎吸收。不是普通的站点污染，是"成为零件"——跟 Endless Mode 的命运相同。

---

### 真结局：逃脱

**画面**：缺口出现。光进来。不是设计好的门——是引擎退化过程中裂开的一道裂痕。你把它当成了门。画面停在光进来的瞬间。不解释、不展示外面是什么。

**圣坛告别**：门打开前，🔧圣坛说最后一句话。规则：遵循声音 3 规则，但唯一一次允许说完整句子。≤20 字。圣坛第一次明确知道你在离开。具体内容留到量产时打磨。

**门打开后**：无文字，无声音。光进来。结束。

**与守卷人的终极对比**：
- 模范生没找到缺口
- 怀疑者找到了但被处理了
- 快乐的根本不想找
- **你找到了，而且走了过去**

#### 真结局后

- 可以继续玩，所有职业所有进阶可用
- 有极微小的变化——某些碎片变了。也许一条新嘟囔，也许一句新格言。不解释不强调
- `hasSeenTrueEnding` flag 存在 MetaState 里

#### 纯圣经层（游戏内零暴露）

| 信息 | 玩家可知 |
|---|---|
| 缺口后面有真实世界 | ❌ |
| 可能被体制抓回来 | ❌ |
| 引擎停是因为打了三个词 | ⚠️ 玩家能观察到但不解释为什么 |
| 引擎重启了，教堂继续 | ❌ |
| 不是门是缺口 | ❌ |
| 你的逃离被归档为"未按流程返回" | ❌ |

### 技术整合规格

#### 1. anomalyLevel 统一变量

```
anomalyLevel = activeModifierInstances.length
视觉：键盘变色强度 = anomalyLevel × 系数
      HUD 噪声强度 = anomalyLevel × 系数
音频：杂音层数 = anomalyLevel（每层一个微弱失调音）
两者同步，不各自计算
```

#### 2. hasSeenTrueEnding flag

```
存储：MetaState（跨 Run 永久保留）
触发：真结局序列完成后设为 true
影响：圣坛嘟囔池 +1-2 条 / Run 开场格言池 +1 条 / 其他微变化量产时定义
不影响机制，纯叙事层
```

#### 3. Codex "拾遗"分类

```
新增分类："拾遗 / Found Notes"
收录：商店批注（看过即留档）
展示：按发现顺序排列，保留手写感排版
可扩展：未来其他非正式碎片也归入此类
```

#### 4. 叙事词与 WordPack 对接

```
新增词属性 isNarrativeWord: boolean
叙事词池：锚点人物名字、条例编号、异文词语（~15-20 个）
频率：每 200-300 个普通词最多插入 1 个叙事词
词长匹配 WordPack 平均词长
不标记、不触发事件、不影响评分
dataminer 可见不影响体验
```

#### 5. 三词钥匙系统

```
掉落条件：仅最高进阶 Run（叙事理由：渗透够深引擎碎片才粘在你身上）
掉落源 A：词包——异文碎片混在禁书里（古书夹了不属于它的纸）
掉落源 B：特定事件——Ritual / Boss 击败 / 特殊商店物品
每次 Run 可掉落多个，允许一次 Run 凑齐三词
钥匙词存在 MetaState（跨 Run 保留，最终层失败时清除）
UI：Collection 三槽位展示（亮/暗，不解释用途）
三词无人类含义，考古型分析什么都找不到
```

#### 6. 最终层停止条件

```
词流从基础速度持续加速
三个钥匙词按固定间隔混入词流（约 1/3、2/3、尾段）
钥匙词出现时词流速度暂时锁定（确保人类可打），打完后继续加速
钥匙词打完时有极微弱音效变化（铅字落格"叮"声稍长）
打完第三个钥匙词 → 引擎停止 → 真结局序列
失败判定：时间耗尽/站点污染 → 被引擎吸收 → 三词清除
```

**三词是暂停键，不是关闭键。** 引擎短暂中断几秒，缺口裂开够你走出去，然后引擎恢复运转。

### 异文版级体系（替代 SCP Object Class）

异文的一切衍生物（词/词包/圣印/遗物/残余异文）共用同一套分级，以铅字排版状态命名——反映异文的危险程度/稳定性。**不使用 SCP 的 Safe/Euclid/Keter 等术语。**

| 稀有度 | 版级（中） | 版级（伪拉丁） | 含义 |
|---|---|---|---|
| common | **定版** | *Fixum* | 已固定在版上，不会动 |
| uncommon | **活版** | *Mobilum* | 能移动但仍在框内 |
| rare | **脱版** | *Solum* | 脱离版面，需重新排 |
| epic | **逆版** | *Inversum* | 自行反转重组，危险但可利用 |
| legendary | **熔版** | *Fusum* | 在熔化，无法维持形态 |
| mythic | **原版** | *Primum* | 先于排版而存在的原始铅 |
| cursed | **逸版** | *Liberum* | 已逃逸，带走了一部分版面 |

**同一分级在不同对象上的解读：**

| 版级 | 用在词包上 | 用在遗物上 | 用在圣印上 |
|---|---|---|---|
| 低版级 | 容易收容的异文 | 轻微渗透，安全使用 | 简单铭纹，容易驾驭 |
| 高版级 | 极难收容的异文 | 深度渗透，危险但强力 | 复杂铭纹，可能反噬 |
| 逸版 | 已逃逸的异文 | 被异文"占据"的物品 | 失控的铭纹 |

**档案中写法**：`版级: 脱版 / Solum`（不写 `Object Class: Keter`）

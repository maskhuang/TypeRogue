# 蜕变师 (Metamorph)

## 职业概览

| 项目 | 设计 |
|------|------|
| 操控维度 | 处理层（技能本身） |
| 核心幻想 | 「技能是活的有机体，在我手中进化适应。别人的 build 是固定蓝图，我的 build 是有机生命体。」 |
| 独有机制 | 变异素 + 蜕变（纯盲盒） |
| 失去 | 附魔选择权（Lv3 直接随机赋予附魔，不给二选一） |
| 构筑风格 | 进化赌徒 |

## 核心资源：变异素

- 第 8 种资源类型（mutagen）
- 单一资源（vs 造词师的 26 种碎片）
- 跨关保留，Run 结束清零
- 通过蜕变师专属技能产出（变异素产出者，套现有产出者公式）

## 隐藏池机制

### 池分配规则

每局（Run）开始时，**转化者、连接者、增幅者**的技能总池各自随机分为两半：

```
转化者总池 (N个)
├── 可见池 (50%) ← 商店正常刷出
└── 隐藏池 (50%) ← 只有蜕变能触及

连接者总池 (M个)
├── 可见池 (50%)
└── 隐藏池 (50%)

增幅者总池 (K个)
├── 可见池 (50%)
└── 隐藏池 (50%)
```

- **产出者不分池**：产出者全部在可见池，商店正常刷出
- 正常玩家（无职业/造词师）：商店只能刷到可见池技能，隐藏池技能永远不会出现
- 蜕变师：商店刷可见池，蜕变触及隐藏池
- 分池在 Run 开始时确定，整个 Run 内不变
- 每次 Run 的分池随机不同（受种子影响）

### 设计理由

- 蜕变不是「重新抽商店里的东西」，而是「接触到别人永远见不到的技能」
- 商店池缩半 → 蜕变是唯一获取另一半的方式 → 蜕变动机强烈
- 产出者不分池：保证所有玩家都能获取基础资源产出能力

## 蜕变机制

### 流程

```
战斗中
├── 按键触发变异素产出技能 → 攒变异素
├── HUD 显示变异素数量
└── 变异素不影响战斗，纯攒

关卡结算 → 蜕变阶段
├── 展示当前所有技能 + 持有变异素数量
├── 点击技能 → 消耗 1 变异素 → 随机变为隐藏池同类型技能
├── 纯盲盒：只知道类型不变，结果完全随机
├── 不可反悔
├── 可继续蜕变 / 跳过
└── 剩余变异素保留到下一关

进入商店（正常流程）
```

### 蜕变规则

- 消耗 1 变异素 / 次
- 技能类型不变（产出者→产出者，转化者→转化者，等）
- 结果从隐藏池同类型中随机抽取
- **全继承**：等级 / 附魔 / 成长值全部保留，零惩罚
- 蜕变次数无限制，变异素产量为天然瓶颈
- 纯盲盒，不可预览不可选择不可反悔

## 失去：附魔选择权

- 普通玩家/造词师：技能 Lv3 时从 2 个随机附魔中选 1
- 蜕变师：技能 Lv3 时直接随机赋予 1 个附魔，不给选择
- 主题契合：蜕变师拥抱不确定性，附魔也是随机的一部分
- 但蜕变全继承附魔 → 不满意可以通过蜕变换技能，附魔保留

## 变异素转化者交互

与碎片资源同样的设计：

| 方向 | 输入读取 | 输出 |
|------|---------|------|
| 变异素→其他 | 本关累计变异素产出量（BattleState 计数器） | 分数/金币等 |
| 其他→变异素 | 对应资源当前值 | 直接加变异素库存 |

- 花变异素蜕变不影响转化者读数 → 囤积无意义
- 计数器每关归零

## 决策三角

```
         技能槽位
        /        \
   分数产出 ←→ 变异素产出
        \        /
         何时蜕变
```

- 绑变异素技能 → 蜕变多但当前关分数弱
- 绑分数技能 → 过关稳但蜕变少，build 固化
- 何时蜕变 → 早蜕变可能找到强力技能，晚蜕变已有 build 更成熟
- 核心张力：当前 build 够用吗？要不要赌一把？

## 专属附魔

蜕变师限定，不进入通用附魔池：

```
独立·适应 (蜕变师限定)
  效果: 本技能每被蜕变一次，永久 +15%（无论变成什么都保留）
  设计: 蜕变越多越强——鼓励反复蜕变同一槽位
  成长存 RunState，跨关保留

独立·不稳定 (蜕变师限定)
  效果: 每关开始时，本技能随机获得一种资源的额外产出（+30%），关末消失
  设计: 每关都是小惊喜，契合「拥抱随机」主题
  每关随机重置，不可控

独立·嗜变 (蜕变师限定)
  效果: 本技能触发时，5% 概率产出 1 变异素（不占产出者槽位）
  设计: 非变异素产出者也有概率攒变异素，降低槽位竞争压力
```

| 附魔 | 核心效果 | 类型 |
|------|---------|------|
| 适应 | 每被蜕变一次 +15% | RunState 永久 |
| 不稳定 | 每关随机 +30% 某资源 | 每关随机 |
| 嗜变 | 触发时 5% 概率产变异素 | 被动概率 |

## 专属遗物

### 初始遗物

```
🧬 原初变异体 (common)
  效果: 每关第一次蜕变免费（不消耗变异素）
  设计: 保底每关至少蜕变一次，体验核心机制
```

### Boss 池升级版

```
🦠 终极突变株 (legendary)
  效果: 每关前两次蜕变免费；蜕变时若结果技能稀有度更高，额外获得 1 变异素
  获取: Boss 掉落池限定
  设计: 原初变异体的全面升级——更多免费次数 + 高稀有度正反馈
```

### 其他专属遗物

```
🔬 基因稳定器 (rare)
  效果: 蜕变后若不满意，本关内再次蜕变同一技能消耗减半（向上取整）
  设计: 降低连续蜕变同一槽位的成本，追求特定技能

🧪 催化注射器 (rare)
  效果: 变异素→其他转化者的读数额外 +30%
  设计: 强化「产变异素同时打分」路线

🌀 混沌种子 (rare)
  效果: 每关结束时，随机一个未附魔技能自动获得随机附魔
  设计: 配合「失去附魔选择权」——附魔来源更多但依然随机

👁️ 深渊之眼 (legendary)
  效果: 商店中可预览 2 个隐藏池技能（不可购买，仅展示）
  设计: 给纯盲盒一点信息补偿——知道隐藏池里有什么，决定是否值得赌

🧫 适者生存 (legendary)
  效果: 蜕变后的技能本关内获得额外 +20% 产出
  设计: 刚蜕变的技能立刻有战力加成，鼓励早蜕变
```

### 遗物汇总

| 遗物 | 稀有度 | 定位 |
|------|--------|------|
| 原初变异体 | common | 初始遗物，保底每关 1 次免费蜕变 |
| 终极突变株 | legendary | Boss 池，升级版 + 稀有度正反馈 |
| 基因稳定器 | rare | 降低重复蜕变成本 |
| 催化注射器 | rare | 强化转化路线 |
| 混沌种子 | rare | 额外随机附魔来源 |
| 深渊之眼 | legendary | 隐藏池信息补偿 |
| 适者生存 | legendary | 蜕变后战力加成 |

## 解锁条件

待定。候选：
1. 通关一次
2. 拥有过 20 个不同技能
3. 到达周目 2

## 两个职业对比

| | 造词师 | 蜕变师 |
|---|---|---|
| 操控层 | 输入层（词语） | 处理层（技能） |
| 独有资源 | 字母碎片（26 种） | 变异素（1 种） |
| 资源编号 | 第 7 种 | 第 8 种 |
| 获取方式 | 专属技能产出 | 专属技能产出 |
| 操作时机 | 商店·造词台 | 关卡结算·蜕变阶段 |
| 失去 | 牌包系统 | 附魔选择权 |
| 确定性 | 高（自选字母拼词） | 低（纯盲盒蜕变） |
| 构筑风格 | 精密工程师 | 进化赌徒 |
| 隐藏池 | 无 | 转化者/连接者/增幅者各 50% 隐藏 |

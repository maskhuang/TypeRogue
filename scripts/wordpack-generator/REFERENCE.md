# REFERENCE · 未受理文本 S 级词对汇编

> 8 机制 × ~120 个 S 级双合法词对 + 叙事 gloss + 反向主题索引。
> **用途**：手工设计 wordpack 时的查阅基底。**不是**自动生成的输入。
> **纪律**：每对必须满足 (1) 双词都合法 (2) 语义偏移 (3) 错位机制真实可信。
> 详见 memory `feedback_unfiled_text_mechanism_taxonomy` / `feedback_unfiled_text_needs_meaning`。

---

## 如何使用本文档

设计 wordpack 时按需查阅：
1. **按 pack tier 选** → 跳到 §10 starter 候选池 / §11 mid-tier / §12 high-tier
2. **按叙事主题选** → 跳到 §9 反向索引（腐烂/失语/印章/抄写员/权威性…）
3. **按机制学习** → §1-§8 逐机制详表，看每个机制的典型形态
4. **查不收录的反例** → §13 附录，避免混入物理破损

## 2 · AI 翻译往返 (机制 2)

整词同域近义替换。**最难察觉**的未受理形态 (玩家以为只是同义词)。

| 原 | 漂移 | 偏移分类 | 叙事 gloss |
|---|---|---|---|
| **avocations** | **profession** | 同域近义 | 副业 → 本职 (叙述者身份悄换) |
| **singular** | **peculiar** | 同域近义 | 独特 → 古怪 (褒贬翻转) |
| **waive** | **decline** | 同域近义 | 法律弃权 → 日常婉拒 |
| **souls** | **people** | 同域近义 | 灵魂 → 人 (灵性维度抽出) |
| **weep** | **shed tears** | 习语化 | 哭泣 → 流泪 (习语→字面) |
| **divers** | **various** | 储语展平 | 古雅 → 现代 |
| **professionally** | **through duty** | 道德叠加 | 职业 → 职责 (引入原文没有的道德含义) |
| **good-natured** | **good** | 修饰丢失 | 性情温和 → 好 (单纯化) |
| gentlemen | people | 性别中性化 | 绅士 → 人 |

补充类候选 (可扩，每段 Bartleby/Kafka 节选可挖到 5-10 对，待批量扫描)：
- conviction / belief · countenance / face · ailment / disease · solitude / loneliness

## 3 · AI 弱模型治愈 (机制 3)

Haiku 修复 OCR 损伤时引入的语法层错误。**整句仍合法**，玩家最难察觉。

| 原 | 漂移 | 类型 | 叙事 gloss |
|---|---|---|---|
| **I know of** | **I knew of** | 时态 | 现在 → 过去 (叙述者的"知"已成历史) |
| **copyists** | **copyist** | 单复数 | 群体 → 单体 (个体溶解为标本) |
| **histories** | **history** | 单复数 | 多样 → 唯一 (失多样性) |
| **:—** | **—** | 标点 | Melville 标志性笔画被现代化抹去 |

可扩：他/他们 (he/they)、过去时/现在时整族、连字符复合词解构、章节符号简化…

## 5 · Redaction (机制 5)

**不直接进 wordpack token**，但记录此处用于剧情/场景文本的"泛化滤镜"。

| 类型 | 原 | 漂移 |
|---|---|---|
| 人名 | Bartleby / Hollis / John Smith | a clerk / the man |
| 地名 | Wall-Street / Hotel Astor | a street / the hotel |
| 数 | thirty years / Room 4-B | many years / a room |
| 作者 | Herman Melville / John Updike | the author / the writer |
| 职衔 | scriveners / law-copyists | clerks / copyists |
| 关系 | my brother / my employee | a man / a worker |

文本应用时 soft 比 hard 更可怕 (soft: 字面上是合法英文，但读起来每个人都是 "a clerk")。

关键性质 ·
1. List + dossier 共占 viewport，模式条 (▾ BROWSE) 是唯一明确告知用户进入"非 scrollback 状态"的 UI 元素，避免 sticky 那种"打字机为啥有粘住的纸"的逻辑别扭。
2. 退出时 list+dossier 像普通 teletype 输出冻结进 scrollback（C 上半段灰文部分演示了这个效果），保留打字机走纸的真实感。
3. ↑↓ 不写入 cmdHistory（自然，因为它不是命令）；BUY/INF 直接作用在选中商品；ESC / 任何非导航命令退出 browse。
4. List 与 dossier 各自独立滚，互不干扰。Dossier 长 INF 不挤压 list 可见区。
